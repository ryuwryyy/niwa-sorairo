## コンセプト

> **未来に住んでから決める。**
>
> 人は家を買いたいのではない。**後悔しない理由**を買いたい。
> そして後悔しない理由は、情報からは生まれない。**体験からしか生まれない。**

**NOT A HOME は、家を買う前に住める会員制サービスである。**
