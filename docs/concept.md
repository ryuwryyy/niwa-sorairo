# NOT A HOME — 事業コンセプト v4.0（原点からの再構築）

> **未来に住んでから決める。**

---

## 0. この文書について

本書は、最初の構想メモに立ち返って書き直したものである。
途中で作った9本の文書は、**事業の中核を取り違えていた**ため、参考資料として残すが本書が優先する。

**何を間違えたか。**
「試住は重い」という外部の指摘を受け入れ、最も検証しやすい部分（現地調査レポート）を事業の中心に据えた。結果、課題は「住民ガチャ」という一点に縮み、**条件の取捨・夫婦の合意・決め手のなさ**という、構想メモに書かれていた本当の課題が扱われなくなった。

重いことは事実である。しかし**重さは、避ける理由ではなく、設計で解くべき対象**だった。

## 1. コンセプト

### 我々が反転させるもの

住宅購入の意思決定は、いま**こういう順序**で行われている。

```
30分の内見  →  契約  →  住む  →  後悔する
```

NOT A HOME は、この順序を逆にする。

```
住む  →  分かる  →  決める
```

> **人は家を買いたいのではない。後悔しない理由を買いたい。**
> そして**後悔しない理由は、情報からは生まれない。体験からしか生まれない。**

### 一行の定義

**NOT A HOME は、家を買う前に住める会員制サービスである。**

## 2. 本当の課題 — 構想メモに忠実に

顧客が困っているのは「家が見つからない」ことではない。

| # | 課題 | なぜ既存サービスで解けないか |
|---|---|---|
| **1** | **どの条件を捨てていいか分からない** | 予算・広さ・駅距離・学区は同時に満たせない。だが**捨てていい条件は、机上では決まらない**。住んでみて初めて「駅8分でも平気だった」「収納は本当に要る」が分かる |
| **2** | **夫婦で合意できない** | 一方は立地、他方は広さ。**言葉で議論するから合意できない。**同じ体験をしていない2人が、想像だけで擦り合わせようとしている |
| **3** | **決め手がない** | 情報はもう十分にある。足りないのは情報ではなく**確信**。SUUMOをいくら見ても決め手は出てこない |
| **4** | **後悔が怖い** | 後悔の正体は「試さなかったこと」。一度も住まずに数千万円を払うから怖い |

**この4つは、すべて同じ一手で解ける。**

> **住んでみること。**

これが「未来に住んでから決める」がUVPとして正しい理由である。思いつきの標語ではなく、**課題4つすべてに対する唯一の共通解**だから中心に置く。

## 3. なぜ試住が中核なのか

前回の設計で、私は試住を「Phase 3」に後退させた。それが誤りだった理由を書く。

### 試住は、夫婦が同じ体験をする唯一の方法である

内見は30分。3泊すれば、こうなる。

- 朝、2人とも実際に起きて、実際に駅まで歩く
- 夜、実際に寝る。上の階の足音を2人で聞く
- 「あなた朝これだけ余裕あるなら、駅8分で平気じゃない？」という会話が、**体験から自然に出てくる**
- 喧嘩もする。**その喧嘩が、本当の争点を露わにする**

> **夫婦の合意は、説得では作れない。共通体験でしか作れない。**
> 試住は「物件を確かめる手段」である以前に、**合意形成の装置**である。

ここが本事業の独自性の核心であり、レポートでは絶対に代替できない部分である。

### 試住は、条件の優先順位を強制的に明らかにする

人は自分の本当の優先順位を知らない。アンケートでは全部「重視する」と答える。
だが**3泊すれば、何が我慢できて何が我慢できないかが、身体で分かる**。

これは我々が教えるのではない。**顧客が自分で発見する。**
だから納得が深く、だから後悔しない。

## 4. 3つのソリューションは、1つの旅程である

構想メモにあった3つを、独立した商品としてではなく、**一本の意思決定の旅**として設計し直す。

```
  ① Living Voice        ② Live Before Buy       ③ Home Detective
   同じ立場の人の声         実際に住んでみる          プロが裏を取る
        │                      │                      │
   条件を仮置きする  →   条件が書き換わる   →   確信に変える
        │                      │                      │
   「自分に似た人は          「実際に住んだら          「あなたが気づいた
     何を捨てたか」            何が分かったか」          ことは、正しい」
```

| | 役割 | 顧客の状態変化 |
|---|---|---|
| **① Living Voice** | 同条件・同エリアの世帯が、**何を捨てて、何を守ったか**を知る | 漠然とした希望 → 仮の優先順位 |
| **② Live Before Buy** | 3泊／7泊／30泊。**夫婦で同じ体験をする** | 仮の優先順位 → **本当の優先順位**（＋夫婦の合意） |
| **③ Home Detective** | 体験で気づいたことに、**中立の第三者が裏付けを与える**。将来リスク・資産性・夫婦の争点分析 | 本当の優先順位 → **確信** |

### 順序が重要である

前回の設計では③（レポート）を単独で売ろうとした。だがレポートは**単独では確信を生まない**。
「知らないことを教えられる」だけでは人は決断しない。
**自分で気づいたことを、専門家に肯定されて初めて確信になる。**

だから③は②の後に来る。順序が価値を作っている。

## 5. 「重い」をどう解くか

試住が重いのは事実である。逃げずに設計する。

### 重さ① 物件をどう用意するか — 自社では持たない

| 供給源 | 供給側にとっての動機 |
|---|---|
| **新築分譲のモデルルーム・完成在庫** | 在庫は損失。**最も購入意欲の高い見込み客**が3泊してくれる |
| **中古の空室**（売主が既に転居済み） | 中古売買では珍しくない。空室期間は売主にとって純粋なコスト |
| **賃貸の空室** | 空室は1日ごとに損失 |
| 家具・住宅設備メーカー | 実際の生活の中で自社製品を体験してもらえる |

> **空室は、誰かの損失である。我々はそれを、誰かの確信に変える。**

これがAirbnbと同じ構造。**我々は不動産を持たず、遊休を動かす。**

### 重さ② 誰が使うのか — 会員制にする

試住を単品で売ると重い。**会員権にすると軽くなる。**

- 月額会員になると、試住・Living Voice・Home Detective が使える
- 「家を探し始めた日から、決めるまで」の期間だけの会員
- 平均在籍6〜12ヶ月。**一生に一度の購買を、期間契約に変換する**

これがNOT A HOTELと同じ構造。**所有ではなく、会員であること自体に価値を置く。**

### 重さ③ 法規制 — 我々は宿を営まない

- 宿泊の提供は行わない。**適法に運営されている施設（民泊届出物件・マンスリー賃貸・モデルハウス見学）へのマッチングに限定**し、契約は供給者と顧客の間で直接結ぶ
- 不動産の媒介・斡旋を行わない（宅地建物取引業法）
- 不動産の持分・権利を販売しない（不動産特定共同事業法）。売るのは**役務の会員権**
- Home Detective では**特定個人の調査を行わない**（探偵業法・人権）

> 規制は制約ではなく、**事業の形を決める設計条件**である。

## 6. なぜこれが「住宅版 NOT A HOTEL」なのか

表面的に似ているからではない。**構造が同じ**だから。

| | NOT A HOTEL | NOT A HOME |
|---|---|---|
| 売っているもの | 別荘ではなく**体験と帰属** | 家ではなく**確信** |
| 不動産の所有 | 持たない／運用に乗せる | **持たない**（遊休を動かす） |
| 収益の形 | 会員・利用 | **会員** |
| 選ばれる理由 | ブランド | **ブランド** |
| 既存業界との関係 | ホテルを作らずホテル業を変えた | **家を売らずに、家の決め方を変える** |

> **NOT A HOTEL がホテルを作らなかったように、NOT A HOME は家を売らない。**

## 7. ゴールへの道筋

**年間1万組の意思決定を支援する。**

| | 内容 |
|---|---|
| 支援の定義 | 会員として、3つの機能のいずれかを使って意思決定に至った世帯 |
| 1万組の意味 | 首都圏の購入検討層のおよそ7〜8%（首都圏の年間取引は約13〜14万件） |
| 到達の形 | 会員数で積む。試住は全員が使うわけではない（**使わなくてもいい**）ことが軽さの鍵 |

**3層の使われ方**（試住の供給制約を、需要側の設計で吸収する）

| 層 | 割合の目安 | 使うもの |
|---|---|---|
| 軽い層 | 多数 | Living Voice ＋ エリア情報だけで決められる |
| 中間層 | 中 | Living Voice ＋ Home Detective |
| 深い層 | 少数 | **試住まで行く**。ここが最も強い体験で、最も語られる |

> **試住は全員に提供する必要はない。**
> だが**試住があることが、このサービス全体の意味を決めている。**
> 深い層の体験が、ブランドと口コミを作り、軽い層を連れてくる。

## 8. 最初にやること

### 検証すべき最重要の問い

前回は「14.8万円を払うか」を最優先に置いた。それは商品が違っていたので、問いも違っていた。

> **本当に検証すべきは、「3泊住んだ夫婦は、意思決定が前に進むか」である。**

**最小の検証：3組の夫婦に、実際に試住してもらう。**

| 見るもの | 合格ライン |
|---|---|
| 試住の前後で、**夫婦の優先順位が変わったか** | 3組中2組で、条件の順位が入れ替わる |
| **争点が言語化されたか** | 「何が合わなかったか」を2人が同じ言葉で説明できる |
| 意思決定が前に進んだか | 「買う／買わない／条件を変える」の判断に至る |
| いくらなら払うか | 体験後に聞く（先に聞かない） |

**やり方**：自分たちの知人夫婦3組。物件は民泊やマンスリーを普通に借りる。原価は数万円。
**プロダクトは作らない。** 必要なのは、3組と、3つの部屋と、前後のインタビューだけ。

### 並行して確かめること

- 空室を持つ側（分譲会社・管理会社・マンスリー事業者）が、試住に物件を出す動機があるか。**3社に聞く**
- 会員モデル（月額）と単品販売、どちらが受け入れられるか

## 9. この構想の弱点（正直に）

| 弱点 | 現時点の見解 |
|---|---|
| 試住の供給が集まるか | **未検証。事業の生死を分ける。**空室が損失であるという論理は成立するが、実際に出すかは別問題 |
| 試住できる物件と、実際に買う物件は別 | 同一である必要はない。**エリアと生活を試す**のが目的。ただし顧客がそれを受け入れるかは要検証 |
| 会員の在籍期間が短い | 一生に一度の購買であることは変わらない。紹介と、購入後の関係設計が必要 |
| 一次調査がデプス数名 | **圧倒的に不足している。**本書の課題設定は構想メモと少数の声に基づく |
| 収益が立つ単価か | 未設計。**3組の試住を終えてから決める**（先に値付けしない） |
