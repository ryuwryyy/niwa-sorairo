# Part A — 顧客向け公開版

## この調査の約束

### 私たちが見るもの

**その場所で暮らすと、実際に何が起きるか。**

内見は、晴れた日曜の昼に、30分だけ、不動産会社の担当者と一緒に見るものです。
私たちは、**平日の朝、平日の夜、休日、そして雨の日**に、一人で行きます。

### 私たちが見ないもの

**特定の個人については、一切調査しません。**

「隣に誰が住んでいるか」を知りたいというご要望は、よく理解しています。
しかし私たちは、隣室の方の職業・家族構成・国籍・生い立ち・経済状況を調べることは**しません**。それは法律に触れる可能性があり、また、差別に加担する行為だからです。

代わりに私たちは、**その建物と地域が、どう管理され、どう使われているか**を見ます。
掲示板に貼られた注意書き、ゴミ集積所の状態、共用廊下の使われ方、駐輪場の整い方。
**人ではなく、その場所に積み重なった「暮らし方の痕跡」を読みます。**

これは遠回りに見えて、実は最も正確です。個人は入れ替わりますが、管理の質は残るからです。

### A. 音

| 項目 | 測定・記録方法 |
|---|---|
| 騒音レベル | 騒音計で **LAeq（等価騒音レベル）／LAmax（最大値）** を各時間帯・各測定点で実測。数値と測定時刻・天候を記録 |
| 測定点 | ①物件のバルコニー面または開口部前 ②建物の前面道路 ③共用廊下 ④最寄りの騒音源側 |
| 音源の特定 | 幹線道路／線路／踏切／学校・園／工場／飲食店の排気・搬入／駐車場／集合住宅の設備音（給排水・エレベーター・室外機） |
| 判断の目安 | 環境省の環境基準および一般的な生活音の目安と対比して提示（※基準はあくまで参考値である旨を併記） |

### B. 光・空気

| 項目 | 記録方法 |
|---|---|
| 日照 | 方位、隣棟間隔、前面建物の高さを実測し、**冬至時の日影を推定**（推定であることを明記） |
| 将来の日照リスク | **隣地の用途地域・建蔽率・容積率・高さ制限から「隣に何が建ちうるか」を算出**。空地・平屋・古家が隣接する場合は必ず記載 |
| 通風 | 開口部の向きと風の通り道 |
| 匂い | 飲食店の排気、工場、下水、ゴミ集積所、ペット臭、畜舎等。**時間帯による変化を記録** |

### C. 管理の質 ＝「住民ガチャ」の観測（本調査の中核）

> 個人は調べません。**集団の振る舞いの痕跡**を読みます。

| 観測点 | 何が分かるか |
|---|---|
| **掲示板の掲示物** | 注意喚起の張り紙は**トラブルの化石**。「騒音にご配慮を」「ゴミの分別を」「不審者情報」の有無・枚数・掲示期間 |
| **ゴミ集積所** | 分別の状態、不法投棄、カラス対策、清掃頻度。**管理規律が最も正直に出る場所** |
| 共用廊下・階段 | 私物の放置、自転車、傘、ベビーカー。生活の滲み出し方 |
| 駐輪場・駐車場 | 整頓、放置自転車、車種の傾向（※個人の特定はしない） |
| エントランス・郵便受け | 清掃、チラシの溢れ、空室の多さ |
| 喫煙・ペットの痕跡 | 吸い殻、ベランダ喫煙の痕跡、規約との整合 |
| **管理組合の書類**（可能な場合） | 長期修繕計画、修繕積立金の水準と将来の値上げ予定、総会議事録の閲覧可否、**滞納状況の有無** |
| 管理会社 | 常駐/巡回の別、対応の実際（一般的な問い合わせで応答品質を確認） |

### D. 周辺環境

| 項目 | 記録方法 |
|---|---|
| 時間帯別の人通り | 各訪問時に**定点で10分間カウント**。属性の記録はしない（人数と流れのみ） |
| 夜間の明るさ | 街灯の配置、駅からの帰路の暗がり、死角 |
| 治安 | **公的な犯罪統計・警察の公開情報のみ**を引用。調査員の主観や噂は記載しない |
| 空き家・空室 | 周辺の空き家率、管理されていない建物の有無 |
| 嫌悪施設・特殊施設 | 公開情報で確認できる範囲 |
| 災害 | ハザードマップ（洪水・土砂・津波・高潮）、地盤、液状化、避難所までの実地歩行 |

### E. 生活動線（実際に歩く）

| 項目 | 記録方法 |
|---|---|
| 駅までの徒歩 | **実測（分・秒）**。坂・階段・信号待ちを含む。不動産広告の「徒歩○分」との差分を明示 |
| 通勤シミュレーション | 実際の時間帯に最寄り駅まで歩き、**乗車位置と混雑**を記録 |
| 保育園・小児科・スーパー | 実地訪問。**距離だけでなく、その時間帯に実際に行けるか**（受入状況・診療時間・営業時間・混雑） |
| 雨天時 | 屋根の有無、水たまり、傘での通行幅 |

> ※「保育園が近くになかったのは後悔した」というのは、ヒアリングで実際に出た声です。距離ではなく**入れるかどうか**を見ます。

### F. 資産性・将来

| 項目 | 記録方法 |
|---|---|
| 都市計画 | 用途地域、再開発、道路計画、将来の街の形 |
| 人口動態 | 町丁目単位の人口・世帯数の推移、年齢構成の変化 |
| 取引事例 | 類似条件の成約事例（公開データ） |
| ランニングコスト | 管理費・修繕積立金の**将来上昇シナリオ** |

### G. 結論（全レポートに必ず含める）

1. **この物件を選ぶべき理由（3つ）**
2. **この物件をやめるべき理由（3つ）** ← **例外なく全レポートに記載します**
3. 総合判定：**推奨 / 条件付き推奨 / 非推奨**
4. 条件付き推奨の場合、**解消すべき条件**を具体的に明記

## 信頼性の担保 — 5つのルール

口コミが信じられないのは、**誰が・いつ・どう見たか分からない**からです。私たちは逆をやります。

1. **一次情報のみ**：実測値・撮影画像・公的データ。伝聞と印象は使いません
2. **実測と推定を分離**：本文中で【実測】【公的データ】【推定】をラベルで区別します
3. **調査員を開示**：氏名・保有資格・調査日時・滞在時間・天候をレポートに記載します
4. **反証を必須化**：「やめるべき理由」を必ず書きます。書けなかった場合はその旨を記載します
5. **報酬は結論に連動しません**：買っても買わなくても料金は同じです。私たちは物件を売らず、仲介手数料も紹介料も一切受け取りません

## やらないことリスト（明示的な禁止事項）

- 特定個人の氏名・職業・家族構成・収入・国籍・出自・障害・信条・病歴の調査および記載
- 近隣住民への「隣にどんな人が住んでいるか」という趣旨の聞き込み
- 属性を理由にした地域・建物の評価（**同和地区・外国人比率等に言及することは、いかなる文脈でも行いません**）
- 噂・SNSの書き込み・匿名口コミを事実として記載すること
- 特定物件の売買の媒介・斡旋、および価格交渉の代理
- 「絶対に大丈夫」「必ず値上がりする」といった断定・保証

# Part B — VC向け設計解説

## B1. この設計が解いている3つの問題

| 問題 | 通常の解 | 我々の解 | 効果 |
|---|---|---|---|
| **「隣人を知りたい」は違法領域** | 調査会社は探偵業届出を取り、個人を調べる | **個人を調べず、集団の管理規律という代理指標に置換** | 探偵業法・差別リスクを回避しつつ、同じ不安を解消する |
| **口コミは信用されない**（検証済） | 件数を増やして平均化する | **一次情報・実測・記名・反証必須**で「口コミではないもの」にする | マンションノート等と土俵を変える |
| **建物検査は既に10万円で存在し、省かれる** | 価格で competing | **建物を扱わず、インスペクターの補完財になる** | 競合が販売チャネルに変わる |

### 代理指標という発明

「住民ガチャ」に対して、業界の常識的な解は2つしかありませんでした。①調べない（＝不動産会社）②個人を調べる（＝探偵・興信所）。
我々は3つ目を取ります。**「掲示板の注意書きはトラブルの化石である」**。

これは単なる回避策ではなく、**精度でも優れています**。個人は転出入で入れ替わりますが、管理組合の規律・管理会社の質・住民の平均的な振る舞いは数年単位で持続するからです。顧客が本当に恐れているのは「特定の隣人」ではなく「**トラブルが起きたときに機能しない共同体**」です。

## B2. 工数と粗利のロードマップ

| フェーズ | 件数 | 1件あたり工数 | 内訳の変化 |
|---|---|---|---|
| 初期（1〜10件目） | 10 | **20h** | 公開データ調査4h／現地6h／周辺4h／執筆6h |
| 中期（同一沿線30件） | 30 | **14h** | 公開データ調査が**エリア共通化で1h**に。執筆はテンプレ化で4h |
| 成熟（アーカイブ後） | — | **8h** | 現地6h＋差分執筆2h。**現地以外はほぼ再利用** |

**粗利率：47% → 62% → 72%**

> 現地6hは**意図的に削らない**。ここを削った瞬間に商品価値が消え、口コミと同じものになる。
> 削るのは**現地以外の全て**。これが本事業のオペレーション原則。

## B3. データ資産化の設計（堀の実体）

全項目を**構造化データとして記録**する。レポートPDFは副産物であり、本体はデータベース。

```
調査レコード
├─ 地点（緯度経度・町丁目・沿線・駅）
├─ 実測値（dB値 × 時間帯 × 測定点 / 日照推定 / 人通りカウント）
├─ 管理指標（掲示物の分類 / 集積所スコア / 共用部スコア）※7段階の規格化スコア
├─ 公的データ（用途地域・ハザード・人口動態・犯罪統計）
└─ 結論（推奨度 / やめるべき理由の分類タグ）
```

**蓄積で起きること**

1. **エリア再利用** — 同一町丁目の2件目以降、D・F項目がほぼ流用可能（工数削減）
2. **相対評価の獲得** — 「この物件の夜間騒音は、同沿線の中央値より8dB高い」という**単独調査では絶対に書けない一文**が書けるようになる。これが競合の後発参入を効かなくする
3. **L1の商品化** — 蓄積されたエリアデータがそのままL1（9,800円・限界費用ほぼゼロ）の中身になる。**L2がL1の原材料を生産する構造**

> つまりL1は集客商品であると同時に、**L2で作った資産を再販する高粗利商品**でもある。

## B4. 品質管理（スケール時に最初に壊れる場所）

調査員をギグ型で組織する以上、**品質のばらつきが最大の事業リスク**。

| 施策 | 内容 |
|---|---|
| 規格化 | 全項目を選択式＋実測値入力のアプリで収集。自由記述は結論部のみ |
| 証拠必須 | 各項目に撮影画像とGPS・時刻のメタデータを紐付け。**証拠のない記載は提出できない仕様** |
| ダブルチェック | 初期100件は統括者が全件レビュー。以降はサンプリング＋低評価案件の全件レビュー |
| 調査員認定 | 建築士・宅建士・元管理会社・地域在住者を優先。初回3件は同行 |
| 顧客からの検証 | 引き渡し後、顧客が実際に住んで「レポートと違った点」を報告する仕組み。**これが精度の唯一の答え合わせ** |

## B5. 未解決の論点（正直に）

1. **需要のタイミングが極端に狭い** — 候補1〜2件に絞った後、契約申込前の数週間だけ。この窓を捕捉できるかがチャネル設計の全て
2. **繁忙期の供給制約** — 住宅購入は季節性が強い。ギグ型でどこまで吸収できるか未検証
3. **「やめるべき」と言われた顧客の反応** — 中立性の証明である一方、返金要求や低評価に直結する可能性。R3として検証予定
4. **管理指標のスコアリング妥当性** — 掲示物やゴミ集積所の状態が、実際の居住満足度とどれだけ相関するか。**購入後追跡データが100件貯まるまで検証できない**
