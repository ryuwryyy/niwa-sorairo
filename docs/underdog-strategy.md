# 弱者の戦略 — 素人が、大手と地元に勝つ方法

> 土地勘がない。人脈がない。作り方も分からない。
> **この3つは、この事業においては弱点ではない。**
> 本書はその理由と、具体的な戦い方を書く。

---

# 第1章 — 素人が知らない、最も重要な事実

## 1.1 法律は、買主に「自分で調べろ」と言っている

不動産取引で買主を守るのは「重要事項説明」である。ところが——

> **周辺環境に関する全ての事項が、宅建業者の重要事項説明義務の対象とは考えられていない。**
> 日照・騒音・振動・臭気・排煙等は主観的要素が大きく、日時・気候により流動的に変化するため、広告にも明確な記載はなく、**現地案内に赴いても買主が把握することが難しいことも少なくない。**
> — 三井住友トラスト不動産「周辺環境と売買契約上の説明義務」

つまり、**我々が売ろうとしている情報は、業界自身が「説明義務の範囲外」と認識している領域**である。

さらに決定的なのは判例の論理だ。

> 航空機騒音については、売主から説明されなくとも**買主が事前に現地を確認するなどして契約締結までに当然気付くべき事柄**であり、騒音の受け止め方も個人差があることから、**売主の告知義務はなかった**と判断された。

**裁判所は「買主が自分で現地を確認すべきだった」という理由で、売主の責任を否定している。**

### この事実が意味すること

| 通説 | 事実 |
|---|---|
| 不動産会社が説明してくれる | 周辺環境は**原則として説明義務の外**。会社が悪いのではなく、法がそう作られている |
| 問題があれば後から責任を追及できる | **「自分で確認すべきだった」で棄却されうる** |
| 現地を見れば分かる | 業界自身が「現地案内に赴いても把握が難しい」と書いている |

> **法律は買主に自衛を求めている。**
> **にもかかわらず、自衛の手段が市場に売られていない。**
> **我々は、その唯一の手段になる。**

これは「あったら便利なサービス」ではない。**法的な自衛手段**である。この一行がこの事業の背骨になる。

### ただし逆の判例もある（正確に扱う）

隣人の迷惑行為が「平穏な住環境を阻害する**環境的瑕疵**」と認定され、売主の説明義務違反として**契約解除と約456万円の損害賠償**が命じられた判例もある。

つまり境界は曖昧で、**取引ごとの総合判断**になる。だからこそ——

- 買主にとって：**曖昧な領域の損失は、自分で確認していないと取り返せない**
- 我々にとって：**「調べた記録がある」こと自体が買主の資産になる**（交渉材料にも、後の証拠にもなる）

> 我々が売るのは情報だけではない。**「確認した」という記録**である。

## 1.2 素人が知らない、業界の構造

| # | 事実 | なぜ素人が知らないか |
|---|---|---|
| 1 | **レインズ（成約データベース）は一般人が閲覧できない** | 宅建業者だけが見られる。情報の非対称は制度で守られている |
| 2 | **両手仲介**がある。買主側の担当者が売主側でもあることがある | 「自分の味方」が構造上そうでない場合がある |
| 3 | 内見には**必ず営業が同行する** | 単独で観察する機会が制度上ほぼない（我々のW8問題の正体） |
| 4 | 管理組合の書類は**買主側の立場がないと取りづらい** | 顧客経由でしか取得できない |
| 5 | **心理的瑕疵は、売買では「◯年経てば告知不要」というルールがない** | 賃貸の3年ルールが独り歩きしている。売買は事案の性質で判断 |
| 6 | 自然死は原則として心理的瑕疵に**該当しない** | 「事故物件」の範囲は世間のイメージより狭い |
| 7 | **宅建業免許を持つと、広告規制など制約が増える** | 免許は資格であると同時に足枷。持たない方が自由に発言できる |

> **7番が特に重要である。**我々が免許を持たないのは「取れないから」ではなく、**取らないことが戦略**だからだ。

## 1.3 そして、業界の収益構造そのもの

不動産業は、**情報の非対称性を収益源にしている**産業である。

これは悪意ではなく構造である。だからこそ——

> **情報を開示する側に回る事業は、業界全体を敵に回す。**

そして、これが本書の中心的な主張につながる。

# 第2章 — 素人であることが、なぜ資格になるのか

## 2.1 業界に人脈がある人は、この事業をやれない

業界に人脈と義理がある人間は、**「この物件はやめたほうがいい」と書けない**。

- 紹介してくれた仲介会社の顔を潰せない
- 次の紹介が来なくなる
- 業界内で「敵」になる

**人脈がないことは、この特定の事業においては参入条件である。**
失うものがない人間だけが、中立でいられる。

> これは強がりではない。**中立性という唯一の資産を守れるのは、業界にしがらみのない人間だけ**という構造の話である。

## 2.2 土地勘がないことは、商品と矛盾しない

一見、致命的に見える。だが——

> **土地勘とは「測らなくても分かる」ことである。**
> **我々の商品は「測って示す」ことである。**
> **土地勘がある人は、測らない。だから売り物にならない。**

| | 土地勘がある人 | 我々 |
|---|---|---|
| 判断の根拠 | 経験・暗黙知 | 実測値・公的データ |
| 他人に売れるか | **売れない**（説明できない） | 売れる（記録が残る） |
| スケールするか | しない（本人しかできない） | する（プロトコルで再現） |
| 堀になるか | ならない（引退で消える） | **なる**（データが残る） |

**ゼンリンの調査員は地元の人ではない。** 全国1,741市区町村を、systematicに歩いて記録する人たちである。必要なのは土地勘ではなく**手順**だった。

### さらに重要なこと：知識の呪い

専門家は「当たり前すぎて気づかない」。

- 玄人：「重説に周辺環境が入らないのは当然でしょう」
- 素人：「なんで入らないんですか？」

**業界が放置している異常に気づけるのは、業界の常識を知らない人間だけである。**
そして我々の顧客も素人だ。**素人の言葉で、素人の不安を扱える**のは我々の側にいる者だけである。

## 2.3 人脈がないことの、実際の意味

「人脈がない」と言うとき、実は何が足りないのかを分解する。

| 必要なもの | 業界人脈が要るか | 実際の入手経路 |
|---|---|---|
| 最初の顧客10人 | **不要** | ターゲットは30代共働きの購入検討者＝**創業者自身の同世代**。素人創業者が唯一持っている資産 |
| 調査員5人 | **不要** | 建築士・元管理会社・**その地域に住んでいる人**。業界人脈ではなく募集で足りる |
| 提携先（インスペクター・FP） | あると速いが不要 | 提案書1枚で会える。彼らは常に**追加価値**を探している |
| 物件情報 | **不要** | 我々は物件を扱わない。これが最大の利点 |
| 現地への立ち入り | **不要** | 顧客に同行する形が正規ルート（→ アクセス階層A/B/C） |

> **物件を扱わないと決めた瞬間に、業界人脈の必要性がほぼ消える。**
> これは規制回避の副産物ではなく、**参入障壁の回避そのもの**である。

# 第3章 — 大企業に、構造で勝つ

## 3.1 「やらない」のではない。「やれない」

大企業が参入しない理由を、精神論ではなく構造で列挙する。

| # | 大企業が構造的にできないこと | 理由 |
|---|---|---|
| 1 | **「買うな」と言う** | 掲載課金・仲介手数料という主要収益と正面から衝突する |
| 2 | **小さい市場に人を張る** | ARR19億円は大手ポータルにとって**社内の新規事業審査を通らないサイズ**。最低採算ラインがある |
| 3 | **1沿線だけ深くやる** | 全国均質を求められる。「東急沿線だけ詳しい」は組織として許容されない |
| 4 | **ブランドリスクを取る** | 「この物件はやめろ」と大手が書けば、訴訟リスクと取引先の喪失が直撃する |
| 5 | **速く動く** | 稟議。法務。この領域は法務が最も慎重になる |
| 6 | **属人的な品質のばらつきを許容する** | 立ち上げ期に必要な「粗くても出す」ができない |

> **最大の盾は「小ささ」である。**
> 19億円という規模は、我々には十分で、大手には小さすぎる。
> **この非対称が続く間に堀を作る。それが3年の意味である。**

## 3.2 ただし、盾は永久ではない

正直に書く。上記はすべて**時間を稼ぐ要因**であって、**参入を不可能にする要因ではない**。

- 収益衝突は、**別ブランド・買収**で回避できる
- 小ささは、我々が大きくなれば解消する（＝成功するほど狙われる）
- 組織の慣性は、外部から人を入れれば変えられる

**だから守りではなく、時間の使い方で勝負する。**

| 3年で作るもの | なぜ金で買えないか |
|---|---|
| **エリア実測アーカイブ** | 過去の騒音・日照・管理状態は、後から遡って測れない。**時間そのものが原材料** |
| **調査員ネットワークと訓練** | 質の高い調査員の組織化と品質の均質化には年単位かかる |
| **中立性の実績** | 「買うなと言った件数」の履歴。**後発は履歴を持てない** |
| **購入後の追跡データ** | 顧客との関係が契約後も続く構造。仲介は契約で縁が切れる |

> **「先に始めた」だけでは堀にならない。「時間を原材料にする商品」を選んだことが堀になる。**

## 3.3 最も危険な競合の、正直な再評価

これまでのドキュメントで、ホームインスペクション大手を「補完財・販売チャネル」と書いてきた。**それは楽観的すぎた。**

**彼らは同時に、最も危険な競合である。**

| 彼らが既に持っているもの | 我々が持っていないもの |
|---|---|
| 調査員（建築士）のネットワーク | ◯ |
| 顧客接点（購入直前という最良のタイミング） | ◯ |
| ブランドと実績 | ◯ |
| **内覧会同行という、建物に合法的に入る商習慣** | ◯ **我々の最大の課題がすでに解決されている** |

彼らが「周辺環境調査」を商品に足した瞬間、我々の優位はかなり失われる。

### 我々の防御（正直に、限定的である）

| 防御 | 強度 |
|---|---|
| 彼らの組織アイデンティティは「建築の専門家」。環境・住民は専門外という自己規定がある | 中（組織の自己認識は変わりにくいが、変わりうる） |
| 全国展開しており、1沿線に密度を作る動きが組織的にできない | 中 |
| 検査は「物件が決まった後」。我々のL2-A（エリア先行）とはタイミングが違う | 中 |
| 我々は建物を扱わないので、彼らにとって**奪う相手ではなく足す相手**に見える | 高（ただし提携している間だけ） |

> **結論：提携は防御である。**
> 敵に回れば我々が負ける可能性が高い相手だからこそ、早期に味方にする。
> 提携が成立すれば、彼らにとって自前で作る動機が下がる。**これが最も重要な生存戦略である。**

# 第4章 — 地域の既存プレイヤーに勝つ

## 4.1 彼らの強さと、その限界

地元の不動産会社・重鎮は、我々にない土地勘と人脈を持つ。だが——

| 彼らが持つもの | 彼らにできないこと |
|---|---|
| 深い土地勘 | **記録に残さない**（頭の中にある） |
| 地元の人脈 | **中立に見えない**（付き合いがある） |
| 長年の信用 | **反証を書けない**（売る側だから） |
| 現地の即応性 | **他エリアに展開できない** |
| — | **引退とともに消える** |

> **暗黙知は、売れない・残らない・移せない。**
> 我々がやるのは、**それを構造化して売れる形にすること**である。

## 4.2 彼らを敵ではなく「供給側」にする

ヒアリングメモにこういう記述があった。

> 「地元のおじちゃんおばちゃんから空いている土地の情報、譲ってもらえないか聞く」

**これは我々もやるべきことだ。ただし逆向きに。**

| 使い方 | 内容 |
|---|---|
| **調査員として採用する** | その地域に住んでいる人こそ、最良の調査員。時間帯別の観察が生活の中でできる |
| **知識の提供者にする** | 「この道は朝どうなりますか」を聞く。**特定個人の話は聞かない**（→ 規制の線） |
| **提携先にする** | 地元の工務店・リノベ業者は、顧客に追加価値を出したい |

彼らにとって我々は、**物件を奪わない相手**である。だから敵対する理由がない。

> **物件を扱わないことが、ここでも効く。**

# 第5章 — 弱者の戦略の実装

「局地戦・一点集中・接近戦」を、この事業に翻訳する。

## 5.1 五つの原則

| 原則 | この事業での実装 | やってはいけないこと |
|---|---|---|
| **局地戦** | 1沿線のみ。他エリアの依頼は**断る** | 全国から受注する（粗利が崩壊する） |
| **一点集中** | 「人と環境」だけ。建物・資金・物件は扱わない | 「ついでに◯◯も」で商品を増やす |
| **接近戦** | 全顧客と直接会う。初期100件は創業者が同席 | 最初からオンライン完結を目指す |
| **一騎討ち** | 大手が構造上入れない土俵を選び続ける | 大手と同じ土俵（物件情報・価格査定）に出る |
| **陽動** | 実測データの公開で、カテゴリ自体を作る | 認知獲得を広告費で買おうとする |

## 5.2 最初の90日、素人が実際にやること

**金も人脈も技術もない状態からの、具体的な手順。**

| 週 | やること | 必要なもの |
|---|---|---|
| 1 | レインズのデータライブラリーで地域別成約データを取得。沿線候補を3本に絞る | **無料。PCだけ** |
| 1–2 | 3本の沿線を実際に乗り、各駅で降りて歩く。**土地勘は、これで作る** | 交通費のみ |
| 2 | 沿線を1本決める。理由を文書化する | — |
| 3 | **自分たちで、1駅分のエリア実査を最後までやる**（平日夜・平日朝・休日） | 騒音計 約1万円 |
| 3–4 | 作ったレポートを、知人5組に**無料で見せて反応を聞く** | 同世代の知人＝唯一持っている人脈 |
| 4 | 共用部アクセスの実地テスト（外周／同行／書類の3パターン） | — |
| 5–6 | インスペクター・FP 各5社に提案（メール1通から始まる） | — |
| 6–10 | **GATE 1：10件提示・5件入金** | Stripeのリンク1本 |
| 10–12 | 結果に応じた次の意思決定 | — |

> **3週目が最も重要である。**
> **自分で1件やりきることが、土地勘・技術・原価の実測・商品定義のすべてを同時に解決する。**
> 人に聞いて回るより速い。

## 5.3 「作り方が分からない」への回答

**最初の50件に、技術は要らない。**

| 必要だと思われがちなもの | 実際に必要なもの |
|---|---|
| Webサービス | スプレッドシートとPDF |
| 予約システム | メールとカレンダー |
| 調査アプリ | 紙のチェックリストとスマホのカメラ |
| データベース | 1枚のスプレッドシート（列は調査項目） |
| 決済基盤 | Stripeの決済リンク |
| AI | **不要**（初期は全件手作業。どこに時間が溶けるかを知るため） |

> システム化は**51件目から**でいい。
> **50件を手でやった人間にしか、何を自動化すべきかは分からない。**

# 第6章 — 素人が必ず踏む地雷

正直に、先に書いておく。

| 地雷 | 症状 | 回避策 |
|---|---|---|
| **業界の人に相談して否定される** | 「そんなの売れないよ」と言われて止まる | **彼らは構造的にそう言う立場にいる。**判断材料は顧客の入金だけ |
| **土地勘を先に付けようとする** | 勉強ばかりして1件も売らない | 1件やる。それが最速の学習 |
| **値引きしてしまう** | 「最初だから安く」で検証データが壊れる | 値引き禁止。売れないなら売れないという事実を持ち帰る |
| **中立を捨てる誘惑** | 送客手数料が魅力的に見える | 定款・利用規約・投資契約で先に自分を縛る |
| **善意で規制を越える** | 調査員が「隣の人はどんな方ですか」と聞く | フォームに人物欄を作らない。仕組みで防ぐ |
| **大手に提携を持ちかけて情報を渡す** | アイデアを説明して自前でやられる | 提携提案では**プロトコルの中身を渡さない**。成果物のサンプルまで |
| **「ついでに物件も紹介して」に応じる** | 宅建業に触れ、中立性も失う | 断る。断ることが商品価値の証明になる |

# 第7章 — 結論

## 我々が持っていないもの

土地勘・人脈・技術・資金・実績・ブランド。

## 我々だけが持っているもの

| 資産 | なぜ大手にも地元にもないのか |
|---|---|
| **「買うな」と言える立場** | 収益が成約に連動していないのは我々だけ |
| **失うものがない** | 業界のしがらみがないのは、人脈がないからである |
| **顧客と同じ視点** | 我々も素人だから、素人の不安が分かる |
| **小さくいられる自由** | 19億円は我々には十分で、大手には小さすぎる |
| **時間を原材料にできる商品を選んだこと** | 過去の実測値は、後から金で買えない |

> **この事業は、業界を敵に回す事業である。**
> **だから、業界に何も持っていない人間が始めるのが最も適している。**

**土地勘がないから測る。人脈がないから中立でいられる。技術がないから手でやる。**
**そのすべてが、この事業では正しい。**

- 判例（隣人の迷惑行為）— 平穏な住環境を阻害する環境的瑕疵と認定し、契約解除および約456万円の損害賠償を命じた事案
- 国土交通省「宅地建物取引業者による人の死の告知に関するガイドライン」（令和3年10月）— 賃貸は3年経過で原則告知不要、**売買には年数ルールを置かず事案の性質に応じて判断**。自然死は原則として非該当
- 株式会社ゼンリン — 住宅地図は調査員の徒歩調査により全国1,741市区町村を収録
