## 0. 前提と、この文書の限界

**「私っぽさ」はリポジトリから推定した。** 違っていたら直してほしい。

| 手がかり | 出どころ | 読み取れる「らしさ」 |
|---|---|---|
| 庭の手入れアプリ「手入れ」。通知・スコア・連続記録をすべてゼロにし、七十二候で季節が応える | `niwa-sorairo` | 成果を急がない。数字で人を急かさない。季節の言葉を持っている |
| デザインリサーチ道具「聴く」。SNS の声を集め、感情語で分ける | `niwa-sorairo/research` | 人の声を聴く人。テクノロジーを「聴く」ために使う |
| 屋久島の「流域のがっこう」。宿と学びの場の予約・運営を自分で作っている | `sumu-yakushima-booking` | 自然の現場と事業の現場の両方にいる |
| 大きな IT 企業の組織に属している記述あり | `CLAUDE.md` §4 | 会社員としての現実も知っている |

つまり「自然 × テクノロジー × 人文」を**実際に手を動かしてつないでいる人**。これがチャンネルの一番の資産になる。

**調べ方の限界(正直に):**

- 今回の調べは公開記事の検索と、ジャンルについての知識による**机上の仮説**。実際の SNS 投稿を 1000 件集めて分けるソーシャルリスニングはまだやっていない。
- 下の「深層心理」と「ペルソナ」は、検証前の仮説として読んでほしい。最後(§11)に、手元の「聴く」で検証する手順を置いた。
- 再生数の予測はしない。言えるのは「伸びる条件を満たしているか」まで。

## 1. 市場の読み(リサーチの要約)

| 観察 | 根拠 | 意味すること |

| Z 世代は「社会的意義」を給与より重視する割合が高い一方、経済的に安定していると感じるのは 3 分の 1 以下 | 各種調査(YPulse 2026-06 ほか) | 「いいことをしたい × お金が怖い」の板挟みは実在する。ここが §4 のペルソナの芯 |

**結論:** 型(歩きラジオ・教養雑談・田舎の映像)はどれも既にある。空いているのは、
**「自然の現場にいて、テクノロジーも書けて、会社の現実も知っている人が、急がない声で話す」**という立ち位置。型ではなく**話し手の位置**で勝つ。

## 3. 「本物らしさ」を求める人の深層心理モデル

庭、茶道、経営、瞑想、禅、哲学、ビジネス、武道。これらに惹かれる人の心を 4 層で置く。

```
[表層の行動]  道具を揃える / 本を読む / 古いもの・手仕事を好む / 「本質」という言葉を使う
      ↑
[現実の悩み]  忙しいのに何も積み上がらない / 自分の仕事が誰の役に立っているかわからない
              / SNS で比べて疲れる / 「意識高い」と思われるのが怖い
      ↑
[深層の欲求]  ①時間に耐える何かとつながりたい(連続性)
              ②自分の手で確かめたい(身体性)
              ③評価から降りても価値がある、と思いたい(存在の肯定)
      ↑
[根の恐れ]    自分は「替えのきく部品」なのではないか
```

**4 つのタイプ(どこで迷っているか):**

| タイプ | 本物を求める理由 | 陥りやすい罠 | 救われる一言 |
|---|---|---|---|
| A. 道具から入る人 | 形を整えると心も整うと信じたい | 道具が揃って満足し、実践しない | 「道具は使ったぶんだけ、あなたのものになる」 |
| B. 知識で武装する人 | 本物を知っていれば偽物にならない | 知るほど動けなくなる | 「知らないまま一回やる方が、知っている人より遠くへ行く」 |
| C. 逃げ場として求める人 | 会社と違う価値軸が欲しい | 本物の世界でも評価を気にする | 「庭は、あなたの成果に興味がない。それが救い」 |
| D. 意味を事業にしたい人 | いいことでお金も回したい | 理想と生活費の板挟み | 「全部を一度に本物にしなくていい。一日一時間だけ本物の時間を持つ」 |

**現実で起きる悩み(共感の入口に使う具体例):**

- 瞑想アプリの連続記録が途切れた日に、瞑想そのものをやめてしまった。
- 茶道を習い始めたが、作法を間違えるのが怖くて楽しめない。
- 「本質的な仕事がしたい」と言ったら、上司に「で、数字は?」と返された。
- 家庭菜園を始めたが、虫に全部食べられて、自分には向いていないと思った。
- 禅の本を 10 冊読んだのに、満員電車ではやっぱりイライラする。
- 「丁寧な暮らし」の投稿を見ると、自分の部屋が恥ずかしくなる。

**ライトな話にする変換ルール:** 重い悩み → 庭や台所の小さな出来事に置き換える → 最後に一つだけ哲学の言葉を添える。説教をしない。結論を言い切らず、「わたしはこう思った」で止める。

## 5. 潜在ニーズと、まだ名前のない分野

意識の高さに疲れた人が、心から救われる場所。まだはっきり名前がついていないもの:

1. **「降りずに、緩める」** — 会社を辞める/移住するという大きな決断ではなく、今の生活の中で速度だけ落とす方法。
2. **「成果のない手入れ」** — 何かを良くするためでなく、関わり続けること自体を目的にする行為(庭、道具、人間関係)。
3. **「小さな流域」** — 自分の行動が水のように下流の誰かに届いている、と感じられる単位で社会貢献を考える。
4. **「答えない時間」** — AI が即答する時代に、わざと答えを保留する時間の価値。
5. **「季節の決算」** — 四半期でなく、五日ごと(七十二候)に小さく振り返る暮らし方。

これらを束ねる新しい言葉の候補:

| 造語 | 意味 | 使い方 |
|---|---|---|
| **手入れ思考** | 作り直さず、少しずつ手を入れて保つ考え方 | 「転職より先に、手入れ思考」 |
| **ゆる本物** | 完璧でなくていい本物。一日一時間だけの本物 | 「ゆる本物でいこう」 |
| **流域で働く** | 自分の仕事を、上流と下流のつながりで見る | 「あなたの仕事の流域はどこまで?」 |
| **七十二候ワーク** | 5 日ごとに季節と自分を振り返る習慣 | 視聴者参加の企画にできる |

## 6. コアアイデアとクリエイティブディレクション

### コアアイデア(一文)

> **人生は、作り直すものではなく、手入れするもの。**
> 庭と山と台所を歩きながら、急がない声で、働き方と生き方の「手入れ」を話すラジオ。

### チャンネル名の案

| 案 | 意図 |
|---|---|
| **手入れラジオ** | 既存アプリと名前がつながる。一番強い |
| ゆるやかな流域 | 屋久島・流域のがっこうと響き合う |
| 歩く、聴く、手を入れる | 3 つの動詞で世界観を言い切る |
| 七十二候ラジオ | 5 日ごとの更新と季節の言葉が企画そのもの |

### トーン(声と言葉)

- 話し手は「先生」ではなく「一緒に歩いている人」。教えない、打ち明ける。
- 一本に一つだけ、古い言葉(禅語・季語・哲学者の一節)を置く。多すぎると説教になる。
- 「〜すべき」を使わない。「〜してみたら、こうだった」で話す。
- ビジネス用語(KPI、成長、効率)は**わざと使って、ほどく**ときだけ出す。

### 映像(低コストで「綺麗」に見せる)

| 要素 | 方針 | 費用 |
|---|---|---|
| 撮影 | スマホを胸か手に持ち、歩く足元・手元・空・植物だけを映す。顔は出さなくていい | 0 円(手持ちのスマホ) |
| 音 | ピンマイク 1 本。風防を必ずつける。音が良ければ映像は多少揺れていい | 3,000〜8,000 円 |
| 色 | 緑と土色を少し落ち着かせる。彩度を上げすぎない | 0 円(無料の編集アプリ) |
| 字幕 | 白の細い明朝体。話の要点だけ。英語字幕も付ける(海外の田舎動画需要) | 0 円(自動字幕を直す) |
| サムネイル | 余白の多い一枚写真 + 縦書きの短い言葉 6〜10 文字 | 0 円 |
| 尺 | 本編 15〜25 分、ショート 30〜60 秒を 1 本につき 2〜3 本切り出す | — |

**一本あたりの作業目安:** 撮影 30 分(歩きながら一発録り) + 編集 2 時間 + サムネと字幕 1 時間。週 1 本で続けられる量にする。

### 続けるための型(毎回同じ)

1. **0:00 季節の一言** — 今日の七十二候と、目の前の景色。
2. **0:30 小さな出来事** — 庭や台所や職場で起きたこと。
3. **3:00 悩みの言葉** — 視聴者からの声、または §3 の現実の悩み。
4. **8:00 寄り道** — 哲学・文学・禅の一節、自然の仕組み。
5. **15:00 わたしの手入れ** — 自分がやってみたこと、失敗したこと。
6. **20:00 宿題ではなく、お土産** — 明日できる小さな一つ。
7. **終わり** — 「また、次の季節に」。

## 7. 強いテーマ 10 案と構成

どれも「ワード」で巻き込めるように、視聴者が真似して使える言葉を一つ持たせている。

### 1. 辞めずに、緩める
- **巻き込むワード:** 「降りずに緩める」
- **対象:** 主ペルソナ(灯さん)
- **構成:** 職場の会議で黙ってしまった話 → 「辞めるか続けるか」の二択の罠 → 自然農の「耕さない」という選択 → 会社の中で耕さないものを一つ決める → お土産: 今週やめる会議を一つ選ぶ
- **ショート切り出し:** 「畑を耕さない農家がいる。会社でも、耕さないものを一つ決めていい」

### 2. 一日一時間の本物
- **ワード:** 「ゆる本物」
- **対象:** 道具から入る人・知識で武装する人
- **構成:** 茶道具を揃えて満足した話 → 本物志向が承認欲求に変わる瞬間 → 千利休の「茶は服のよきように」 → 完璧でない本物の例 → お土産: 明日の朝、一杯だけ丁寧にいれる

### 3. 庭はあなたの成果に興味がない
- **ワード:** 「成果のない手入れ」
- **構成:** 剪定を失敗して木が変な形になった話 → でも翌年また芽が出た → 評価されない時間の回復力 → 心理学の「自己決定感」 → お土産: 誰にも見せない手入れを一つ持つ

### 4. 答えない時間 — AI 時代の禅
- **ワード:** 「答えない時間」
- **構成:** AI に何でも聞いてしまう自分 → 禅の公案は答えのない問い → 屋久島の森で圏外になった日 → 保留する力が判断力を作る → お土産: 一日一つ、検索しない疑問を持ち歩く

### 5. あなたの仕事の流域
- **ワード:** 「流域で働く」
- **構成:** 屋久島の川がどこから来てどこへ行くか → 自分の仕事の上流(誰から受け取るか)と下流(誰に届くか) → 社会貢献は大きな川でなく小さな支流から → お土産: 自分の仕事の「下流にいる人」を一人思い浮かべる

### 6. 七十二候で働く
- **ワード:** 「七十二候ワーク」
- **構成:** 四半期目標に追われる話 → 季節は 5 日で変わる → 小さな決算を 72 回する生き方 → 視聴者参加: コメントで「今の候の一行日記」 → シリーズ化(5 日ごと更新のショート)
- **強み:** 毎回の季語が自然にタイトルになる。続けやすい

### 7. 考察しない読み方 — アニメと畑
- **ワード:** 「作者のいない物語」
- **構成:** 好きなアニメの考察動画を見すぎて疲れた話 → 正解探しの疲れ → 畑は誰も作者がいない物語 → 正解のない読み方を楽しむ → お土産: 一つの作品を「考察せずに」もう一度見る
- **注意:** 作品の画像や映像は使わない。言葉と自分の映像だけで語る(権利のため)

### 8. 意識高い系の、その後
- **ワード:** 「意識高い系の手入れ」
- **構成:** 自分が「意識高い」と言われて恥ずかしかった話 → 理想を持つことは悪くない → 理想と生活の間で燃え尽きる構造(§3 の 4 層) → 理想を小さく分ける → お土産: 理想を 1/10 にして今週やる

### 9. 型があるから、自由になれる
- **ワード:** 「守破離の手入れ」
- **構成:** 武道・茶道の型の話 → 型のない毎日は毎日が本番で疲れる → 朝のルーティンを「型」として作る → 型を破るのは、型が身についた後でいい → お土産: 毎朝同じことを一つだけ決める

### 10. 通知ゼロのアプリを作った話
- **ワード:** 「急かさない設計」
- **構成:** 庭アプリから通知とスコアを全部消した理由 → 連続記録が途切れて瞑想をやめる問題 → テクノロジーは人を急かすこともできるし、待つこともできる → 作る側の倫理 → お土産: スマホの通知を一つだけ切る
- **強み:** 本人の実例なので、他の誰にも作れない回。チャンネルの名刺になる

## 8. 台本(第 1 回: テーマ #1「辞めずに、緩める」)

尺の目安 18 分。【 】は映像、( )は話し方の指示。季語は寒露の初候「鴻雁来る」(10 月 8 日ごろ〜)の公開を想定。撮る日に合わせて差し替える。

---

**【足元。朝露の残る草。歩く音】**

おはようございます。
今日は、二十四節気でいうと寒露。七十二候では「鴻雁来る(こうがんきたる)」。雁が北から渡ってくる頃です。
(間)
歩きながら、少し話します。

**【庭の端。抜かれていない草】**

この前、職場の会議で、言いたいことがあったのに、黙ってしまいました。
「この進め方、ちょっと急ぎすぎじゃないですか」って。
言えなかった帰り道に思ったのは、「もう辞めたほうがいいのかな」でした。

でも、少し歩いて、気づいたんです。
わたしはいつも、**「辞める」か「我慢して続ける」か**、二つしか持っていない。

**【手のアップ。土を触る】**

自然農という育て方があります。
畑を耕さない。草も全部は抜かない。肥料もほとんど入れない。
最初に聞いたとき、正直、それって怠けてるだけでは、と思いました。(笑うように)

でも、やってみるとわかるんです。
耕さないと、土の中の小さな生き物や、根っこが作った道が、そのまま残る。
人間が全部やり直さないほうが、土は育つことがある。

**【空。雲】**

会社も、たぶん少し似ています。
全部をひっくり返さなくてもいい。
辞めなくてもいい。
**「耕さないもの」を一つだけ決める。** それだけで、土の感じが変わることがある。

(間)

**【歩く。木漏れ日】**

ここで、少し寄り道をします。
禅に「放下着(ほうげじゃく)」という言葉があります。
持っているものを、下ろしなさい、という意味です。

面白いのは、捨てなさい、ではないところ。
下ろす。いったん、地面に置く。
また必要なら、拾えばいい。

わたしは、これを「降りずに、緩める」と言い換えています。
仕事から降りるのではなく、握りしめていた手を、少しだけ緩める。

**【台所。お湯を沸かす】**

じゃあ、具体的に何をしたか。

わたしは、毎週出ていた会議を一つ、「議事録を読むだけにしてもいいですか」と聞いてみました。
すごく緊張しました。
返事は、あっさり「いいよ」でした。

(間)

拍子抜けしたのと同時に、少し悲しくなりました。
わたしが「辞めたい」とまで思っていた重さの一部は、**自分で耕しすぎていた**だけだったのかもしれない。

**【コメント欄の声を読む想定。画面は庭の椅子】**

この話をする前に、こんな声を見かけました。
「社会にいいことをしたいけど、今の仕事を辞める勇気もお金もない」。

わかります。わたしもそうでした。今もそうかもしれません。

でも、いいことって、大きな川の本流だけじゃなくて、
小さな支流からも流れていくと思うんです。
今の場所で、手を少し緩めて、空いた時間で、誰か一人の下流に水を流す。
それも、ちゃんと社会につながっている。

**【夕方の光。帰り道】**

今日のお土産です。宿題ではありません。

**今週、「耕さないもの」を一つだけ選んでみてください。**
出なくていい会議。返さなくていい即レス。整えなくていい資料の見た目。

全部じゃなくていいです。一つだけ。
選べなかったら、それでも大丈夫。選ぼうとしたこと自体が、もう手入れです。

(間)

雁が渡ってくる季節です。
雁は、全部の距離を一羽で飛ばないそうです。先頭を交代しながら行く。
わたしたちも、たまには先頭を譲っていい。

では、また次の季節に。

---

**概要欄の文:**

> 辞めるか、我慢するか。二つしかないと思っていた帰り道の話です。
> 自然農の「耕さない」と、禅の「放下着」を手がかりに、仕事を降りずに緩める方法を話しました。
> 今週の「耕さないもの」、よかったらコメントで教えてください。

## 11. 次の一手 — 仮説をソーシャルリスニングで確かめる

§3 と §4 は仮説。手元の「聴く」(`research/`、スキル `social-deepdive`)で、実際の声と照らす。

**集める検索語(案):**

- 悩みの声: 「意識高い系 疲れた」「社会貢献 したい お金」「辞めたい でも」「瞑想 続かない」「家庭菜園 失敗」「丁寧な暮らし しんどい」
- 本物志向の声: 「茶道 始めた」「禅 本 読んだ」「自然農 始めた」「武道 大人から」
- 視聴者の声: 「散歩 ラジオ 好き」「作業用 ラジオ 落ち着く」「田舎 vlog 癒される」

**確かめること:**

| 仮説 | 確かめ方 | 外れたら |
|---|---|---|
| 主ペルソナの芯は「いいことをしたい × お金が怖い」 | 感情語グループで「悪い・嫌い」側に、この板挟みの声がどれだけあるか | 芯を「疲れ」「比較」側へ移す |
| 「降りずに緩める」は刺さる | 「辞めたい」系投稿のうち、二択に苦しむ声の割合 | テーマ #1 の順番を下げる |
| 本物志向に承認欲求の自己ツッコミが効く | 「意識高い」への自嘲の投稿の多さ | #8 を強める/弱める |

**費用の注意:** Brave と Claude の呼び出しは費用がかかる。「聴く」は質チェックで止まり、要約・洞察はボタンを押した時だけ呼ぶ設計なので、その手順を守る(`CLAUDE.md` §3)。
