**作成日：2026-09-18 ／ 前提：年収780万円・正社員（在職中）**

# 第0章 — 最初に、やってはいけないことを3つ

金額の話をする前に、**これを知らずに始めると事業が終わる**ことを3つ書く。

## ❌ 1. 住宅ローンで買った家を、試住や民泊に使ってはいけない

住宅ローンは**「本人が居住するための住宅」**にしか使えない。事業用・賃貸用に使えば**用途外使用**であり、契約違反にあたる。発覚すれば金融機関から**一括返済を求められる**（期限の利益の喪失）。

> **年収780万円で借りられるおよそ5,900万円は、この事業には投入できない。**
> これが本計画の最大の制約であり、最初に確定させるべき事実である。

事業に使う物件の資金は、**事業用のローン（公庫・アパートローン等）か、出資**で調達する。混ぜてはいけない。

## ❌ 2. 登録を受けずに「オーナー権」を売ってはいけない

「みんなでお金を出して不動産を持ち、収益を分ける」——これは**不動産特定共同事業法**の規制対象である。
**登録または許可なしにこれを行うことは、無登録営業にあたる。**

個人間の口約束で「1口100万円でオーナーになりませんか」と声をかけることは、**この事業ではできない。**
→ 正しい道は第3章に書く。

## ❌ 3. 自分で宿泊を提供してはいけない（許可なしには）

試住を自社で宿泊事業として行えば、旅館業法・住宅宿泊事業法の領域に入る。
**適法に運営されている施設へのマッチングに限定する**というのが本事業の設計である（`concept.md` 参照）。

# 第1章 — ビジネスモデル

## 1.1 お金の入り口と出口

**会社が稼ぐお金**

| # | 収益 | 内容 | 性質 |
|---|---|---|---|
| **A** | **会員費** | 家を探し始めてから決めるまでの期間、月額 | **主力**。積み上がる |
| **B** | 試住マッチング手数料 | 宿泊費に対する一定率 | 変動 |
| **C** | Home Detective（調査レポート） | 都度 | 高単価・低頻度 |
| **D** | シェアオーナー事業の運営報酬 | 賃料収入等に対する一定率 | 小さい |
| — | ❌ 不動産会社からの紹介料 | **取らない** | 中立性を失うため |

**会社が使うお金**

| 費目 | 内容 |
|---|---|
| 人件費 | 当初は創業者のみ（在職のまま） |
| 物件関連 | **自社では買わない**。借りる・使わせてもらう |
| 調査・現地費用 | 交通費、騒音計等 |
| 法務・登録 | 不特法の登録、弁護士確認 |

> **重要：シェアオーナー事業（D）は、収益源ではない。**
> 運営報酬は小さく、これで食べていくことはできない。
> シェアオーナー事業の目的は3つある——**①物件を確保すること ②ブランドを作ること ③シェアオーナー自身が最初の顧客になること。**

## 1.2 なぜ物件を持たないのか

| 持つ場合 | 持たない場合（本事業） |
|---|---|
| 1棟ごとに数百万〜数千万円が必要 | **他人の空室を使う** |
| 空室リスクを自社で負う | 空室は元々の損失。我々が減らす側 |
| スケールに比例して資金が要る | 会員が増えても資金は増えない |
| 投資家に「不動産屋」と見られる | **ソフトウェア的に見える** |

**ただし例外がひとつある。** 1棟だけは自社の関与で持つ（シェアオーナー方式で）。
理由は**「見せる家が1軒もないサービスは、誰にも説明できない」**からである。これを**旗艦**と呼ぶ。

# 第2章 — 資金の4階建て

あなたが使える資金は4種類ある。**性質がまったく違うので、絶対に混ぜない。**

| # | 資金源 | 性質 | 何に使えるか | 規模の目安 |
|---|---|---|---|---|
| **①** | 住宅ローン | 個人の負債 | **自分が住む家だけ** | 約5,900万円 |
| **②** | 日本政策金融公庫 | 会社の負債 | 運転資金・改修 | 上限7,200万円 |
| **③** | エンジェル投資 | 会社の資本 | 検証・人件費 | 100万〜3,000万円 |
| **④** | シェアオーナー出資 | **不特法の出資** | 物件の取得 | 一人100万円・総額1億円 |
| ⑤ | 補助金 | 返済不要 | 改修・販路開拓 | 数十万〜200万円 |

---

## ① 住宅ローン — 約5,900万円（ただし事業には使えない）

**計算の前提**

| 項目 | 値 |
|---|---|
| 年収 | 780万円 |
| 返済負担率 | **35%**（フラット35は年収400万円以上で35%。多くの金融機関の目安は30〜35%） |
| 年間返済可能額 | 273万円（月22.75万円） |
| **審査金利** | **3.0%**（実際の金利ではなく、審査だけに使う高めの金利。各行おおむね3%前後） |
| 返済期間 | 35年 |

**→ 借入可能額の目安：約5,900万円**

**実際の返済額**（実行金利を変動0.5%と仮定した場合）

| 借入額 | 月々の返済 |
|---|---|
| 5,900万円 | 約15.3万円 |
| 4,000万円 | 約10.4万円 |
| 3,000万円 | 約7.8万円 |

> **注意：これは「借りられる額」であって「借りていい額」ではない。**
> 返済負担率35%は金融機関の上限であり、生活は苦しくなる。25%（約4,200万円）が無理のない目安とされる。

### この5,900万円を、事業にどう関係させるか

**直接は使えない。ただし2つだけ、正当な関わり方がある。**

| 使い方 | 可否 | 説明 |
|---|---|---|
| 事業用物件を住宅ローンで買う | **❌ 不可** | 用途外使用。一括返済を求められる |
| 自宅の一部を試住に貸す | **❌ 原則不可** | 同上。賃貸併用住宅は別商品（アパートローン等）になる |
| **自分が移住して、そこに住む** | **⭕ 可** | 糸島や屋久島に自分が住むなら、それは自宅。**ただし事業には使わない** |
| **在職を続け、与信を保つ** | **⭕ 最重要** | 会社の融資審査で、代表者に安定収入があることは強く効く |

> **結論：住宅ローンは事業計画から外す。**
> **代わりに「年収780万円の正社員である」という属性そのものを、②の融資で使う。**

## ② 日本政策金融公庫 — 創業融資（本命の1つ）

**制度：新規開業・スタートアップ支援資金**（旧・新創業融資制度は2024年3月末で終了し、これに統合）

| 項目 | 内容 |
|---|---|
| 融資限度額 | **7,200万円**（うち運転資金4,800万円）※2024年4月に3,000万円から拡充 |
| **自己資金要件** | **撤廃された**（旧制度は1/10必要だった） |
| 担保・保証人 | **原則不要**。代表者の個人保証も原則不要 |
| 対象 | 新たに事業を始める方、または事業開始後おおむね2期以内 |

> **自己資金要件が撤廃されたことと、代表者保証が原則不要であることは、素人の起業にとって決定的に有利である。**
> ただし実務上、自己資金が乏しいと審査で不利になりうる。

### あなたの場合に効くこと

| 要素 | 効き方 |
|---|---|
| **年収780万円の正社員** | 返済原資として評価される。**在職のまま申し込むのが有利** |
| 自己資金 | 貯蓄があれば示す。要件ではないが印象が変わる |
| 事業計画 | **これまで作った文書一式がそのまま使える** |
| 特定創業支援等事業の証明書 | 取得していると評価されやすい（第4章） |

**現実的な申込額の目安：300万〜1,000万円**
上限7,200万円は「制度上の枠」であって、創業時にこの額が出ることは稀である。

## ③ エンジェル投資 — 株式で調達する

| 項目 | 内容 |
|---|---|
| 1件あたりの出資額 | **100万〜3,000万円**（シード投資家は100万〜1,000万円が中心） |
| 最初の選別軸 | **「5〜7年でIPOまたはM&Aの見込みがあるか」** |
| 判断材料 | 実績ではなく将来性・新規性・ビジネスモデル |

### エンジェル税制（相手が必ず気にする）

**プレシード・シード特例**（2023年4月に拡充）

| 内容 |
|---|
| 出資額を、その年の**株式譲渡益から控除**できる |
| 控除の上限は**年間20億円** |
| 将来売却したときの**取得価額の調整がない**（＝課税の繰延べではない） |

> **これは相手にとって非常に大きい。**ただし**会社側が要件を満たし、確認を受ける必要がある。**
> **確認が済んでいないのに「使えます」と言ってはいけない。**「要件充足を目指しています」までが言える範囲である。

### 融資と出資、どちらを先にするか

| | 融資（②） | 出資（③） |
|---|---|---|
| 返す必要 | **ある** | ない |
| 株式の希薄化 | ない | **ある** |
| 審査で見られるもの | 返済能力 | 将来の大きさ |
| **初期の相性** | **◎ こちらが先** | 事業の形が固まってから |

> **推奨：②を先に、③を後に。**
> 検証段階（数百万円）で株式を渡すのは、あとで必ず後悔する。
> **公庫で検証資金を作り、「検証が終わった事業」として③に臨む。**

## ④ シェアオーナー — 小規模不動産特定共同事業

**これが「個人間でのオーナー権の販売」の、唯一の正しい形である。**

| 項目 | 小規模不動産特定共同事業 | 通常の不動産特定共同事業 |
|---|---|---|
| 手続き | **登録** | 許可 |
| **資本金** | **1,000万円** | 1億円（第1号事業） |
| 出資総額の上限 | **1億円以下** | なし |
| **一人あたり** | **100万円以下** | なし |

### 登録までの現実的な順序

1. **まず登録なしでできることをやる**（試住のマッチング、会員サービス、調査レポート）
2. 事業が回り始めてから、**資本金1,000万円を用意して登録申請**
3. 登録後に、はじめてシェアオーナーを募集する

> **登録前に出資を募ることは、絶対にしない。**
> 「関心がある方はご連絡ください」というリスト作りも、**募集と受け取られない表現に厳密に限る**こと。弁護士に確認する。

### 1号物件のモデル（仮）

| 項目 | 金額 |
|---|---|
| 中古戸建の取得 | 800万円 |
| 改修 | 400万円 |
| **合計** | **1,200万円** |
| 調達 | **12人 × 100万円**（一人100万円の上限内・総額1億円の枠内） |

**運用（保守的な想定）**

| 項目 | 年額 |
|---|---|
| 試住の収入（1泊12,000円 × 年100泊） | 120万円 |
| 経費（清掃・光熱・管理・固定資産税） | ▲60万円 |
| 運営報酬（会社が受け取る・15%） | ▲18万円 |
| **オーナーへの分配原資** | **42万円** |
| **1口100万円あたり** | **3.5万円／年（3.5%）** |

**そしてオーナーは、自分でも泊まれる。**

> **別荘を単独で買えば、年間50万〜120万円の維持費が出ていくだけである。**
> **こちらは、100万円で「使えて、しかも少し戻ってくる」。**
> ——これがシェアオーナーへの提案の核心である。

**必ず併記すること**：元本保証はない。分配が出ない年もある。

# 第3章 — 補助金

## 3.1 全国で使えるもの

### 小規模事業者持続化補助金【創業型】

| 項目 | 内容 |
|---|---|
| 補助上限 | **200万円** |
| 補助率 | **2/3** |
| インボイス特例 | **+50万円** |
| 要件 | 創業1年以内（公募締切日から1年以内の開業日）かつ**「特定創業支援等事業」の証明書**を保有 |

> **この「特定創業支援等事業の証明書」が、鍵になる。**
> 自治体が実施する創業塾等を受講して取得する。**台東区にはこの制度がある**（第4章）。

## 3.2 補助金の性質を誤解しない

| 誤解 | 事実 |
|---|---|
| もらえるお金 | **原則は後払い（精算払い）。**先に自分で払う必要がある |
| 誰でも通る | 審査がある |
| 自由に使える | **対象経費が決まっている** |
| すぐ入る | 申請から入金まで数ヶ月〜1年 |

> **補助金は資金繰りの解決にならない。** 立て替える現金が別に要る。
> 補助金は「使ったお金の一部が戻ってくる制度」と理解する。

## 4.1 結論を先に

| **台東区** | **本社・創業支援の受け皿** | **最初** |

**理由：制度の厚みと、需要の性質が場所ごとに違うから。**

## 4.2 台東区 — 本社を置く

**役割：創業支援を受け、補助金の要件を満たし、投資家に会う場所。**

| 制度 | 内容 |
|---|---|
| **特定創業支援等事業** | したまちTAITO創業塾、たいとう朝日創業塾、創業個別ゼミ。経営・財務・人材育成・販路開拓を継続的に学ぶ。**→ 証明書が出る** |
| **開業支援資金（台開）** | 創業後1年未満で、700万円以内は7年以内、700万円超は9年以内の融資制度 |
| **空き家・空き店舗リノベーション準備助成金** | 北部地区の空き家・空き店舗の**所有者**に、残置物撤去・清掃・老朽箇所の修繕費を**最大50万円（助成率1/2）** |
| 商店街空き店舗活用支援 | 改修費 最大200万円（1/2）、賃借料 家賃の1/2・月額5万円まで3年間 ※**令和8年度の受付は終了** |

### 台東区が効く理由 — 補助金の連鎖

```
① 台東区の創業塾を受講
        ↓
② 「特定創業支援等事業」の証明書
        ↓
③ 小規模事業者持続化補助金【創業型】に応募できる（上限200万円・2/3）
```

> **証明書は無料で取れて、200万円の補助金の入口になる。**
> **最初にやるべき手続きはこれである。**

**注意**：リノベーション準備助成金は**空き家の所有者**向けである。我々が借りる側として直接受けるものではない。
**ただし、これは強力な営業材料になる。**「御社が助成金を使って整備できます」と所有者に伝えられる。

## 4.3 糸島 — 1号物件を置く

**役割：実際に試住をやってみる最初の場所。**

| 制度 | 内容 |
|---|---|
| **地域循環型創業支援補助金** | 市内で事業を開始する方を支援。創業時または創業間もない時期の費用の一部を補助 |
| **空き家活用推進補助金** | 空き家を売却・賃貸するために相続登記や家財撤去をして**空き家バンクに登録した所有者**に、対象経費の**1/2**を補助 |
| 空き家バンク | 登録料・利用料は無料 |
| **戸建て住宅ニーズバンク**（令和6年2月〜） | 戸建てを探す人が条件を登録し、**所有者とつなぐ仕組み** |

### なぜ糸島が1号に向いているか

| 理由 | 説明 |
|---|---|
| 移住先として認知がある | 「糸島に住みたい」と検索する人が既にいる＝需要を作らなくていい |
| 福岡市に近い | 仕事を変えずに移住できる＝**試住の意味が最も大きい層がいる** |
| 空き家バンクと補助金が揃っている | 物件を出す側にメリットを提示できる |
| **戸建て住宅ニーズバンク** | 行政が「探す人と持つ人をつなぐ」仕組みを既に作っている。**我々と目的が一致している** |

**最初の一手**：空き家活用推進補助金を**所有者に紹介しながら**物件を探す。
「私たちに貸していただければ、登録と整備に補助金が使えます」という話ができる。

## 4.4 屋久島 — 旗艦にする（ただし最初ではない）

**役割：ブランドと、環境保全の物語。**

| 制度 | 内容 |
|---|---|
| **移住支援金** | **東京23区に在住または通勤**していた方が転入し、就業要件を満たすか**起業支援金の交付決定**を受けた場合に交付。**世帯100万円／単身60万円** |
| 空き家バンク | 町が運営 |
| **移住体験住宅**（屋久島町暮らし体験住宅） | **町が既に「お試し移住」の仕組みを持っている** |

### 注目すべき2点

**① 移住支援金の要件に、あなたが当てはまる可能性がある**
東京23区に在住または通勤しているなら、**転入＋起業支援金の交付決定**で世帯100万円／単身60万円。
**ただし要件は厳密**なので、必ず町に直接確認すること。

**② 町がすでに「暮らし体験住宅」を持っている**
これは競合ではなく、**我々のコンセプトが行政公認であることの証拠**である。
「試住は有効だと、町がすでに証明している」と言える。

### なぜ最初ではないのか

| 理由 |
|---|
| **アクセスコストが高い**（鹿児島から船か飛行機）。3泊の試住に、往復の負担が大きい |
| 人口が少なく、母数が小さい |
| 移住の難易度が高く、検証としては極端 |
| **世界自然遺産の島で、素人がいきなり事業を始めるのは地域から警戒される** |

> **屋久島は、実績を作ってから行く場所である。**
> 糸島で1軒やり、地域と良い関係を作った実績を持って行けば、話が通りやすい。
> 逆に、実績ゼロで世界遺産の島に行くのは、最も難易度が高い。

**環境保全の文脈**：屋久島には環境文化財団があり、自然と共生する地域づくりを掲げている。

# 第7章 — 正直に書く、未確定と危険

## 7.1 まだ確認していないこと

| # | 未確認事項 | 確認方法 |
|---|---|---|
| 1 | 各補助金の**最新の公募状況と要件** | 各自治体・事務局の公式サイト。**制度は毎年変わる** |
| 2 | 移住支援金の要件に自分が該当するか | 屋久島町に直接確認 |
| 3 | 公庫が実際にいくら貸すか | 事前相談 |
| 4 | 不特法の登録が実際に通るか | **個別判断。行政書士に相談** |
| 5 | エンジェル税制の要件を自社が満たすか | 確認申請が必要 |
| 6 | 住宅ローンの実際の借入可能額 | 各行の審査基準は非公表。**仮審査で確認** |

## 7.2 最も危険な誤り

| 危険 | 結果 |
|---|---|
| **住宅ローンを事業に使う** | 契約違反。**一括返済請求** |
| **登録前にオーナー権を売る** | 無登録営業 |
| **「必ず儲かります」と言う** | 法令違反になりうる |
| **補助金をあてにして資金繰りを組む** | 後払いのため資金ショート |
| 退職してから始める | 生活の圧力で、判断が歪む |
