## 1. 課題の再定義

### 1.1 通説 vs 実態

| 通説（既存プレイヤーの前提） | 実態（我々の仮説） |
|---|---|
| 顧客は「良い物件」を探している | 顧客は「決めていい理由」を探している |
| 情報が足りない | 情報は多すぎて、**優先順位が決められない** |
| 意思決定者は1人 | 意思決定者は**2人**（＋両親という隠れステークホルダー） |
| ゴールは契約 | 顧客のゴールは**10年後に後悔していないこと** |

### 1.2 意思決定が壊れる4つの瞬間

1. **条件の絞り込み** — 予算・広さ・駅距離・学区は同時に満たせない。何を捨てるか決められない
2. **夫婦の非対称** — 一方は「立地」、他方は「広さ」。言語化されないまま争点がズレ続ける
3. **アドバイザーの利益相反** — 相談相手（仲介・ハウスメーカー・銀行）は全員「買わせる側」。中立の第三者が市場に存在しない
4. **反証情報の欠如** — 「この家はあなたに向いていない」と言う人が誰もいない

> **NOT A HOMEの存在意義＝「買わない方がいい」と言える唯一の相手になること。**

## 3. 競合分析

### 3.1 競合マップ（2軸：中立性 × 意思決定への関与度）

```
                 高 中立性
                     │
   FP・住宅診断士     │     ★ NOT A HOME
   （属人・非スケール）│    （中立×意思決定深関与）
                     │
 ────────────────────┼──────────────────── 意思決定関与度 高
                     │
   価格査定ツール     │   SUUMO / HOMES / at home
   （情報のみ）       │   仲介・ハウスメーカー
                     │   （送客モデル＝利益相反）
                 低 中立性
```

### 3.2 個別競合と非対称優位

| プレイヤー | 収益源 | 弱点 | 我々の非対称性 |
|---|---|---|---|
| SUUMO / LIFULL HOME'S | 掲載課金・送客 | 掲載主＝不動産会社のため「買うな」と言えない。カニバリのため参入不可 | **顧客から課金**するので「買うな」と言える |
| 大手仲介（三井・住友・東急） | 仲介手数料3% | 完全な利益相反。意思決定支援は営業行為 | 免許を持たない＝中立性が構造的に担保される |
| ハウスメーカー | 建築請負 | 自社商品のみ | 全ブランド横断で比較 |
| 住宅FP・ライフプラン相談 | 保険販売・相談料 | 属人的、資金計画に偏り、生活価値観は扱わない | AIでスケール、**価値観・夫婦合意**まで踏み込む |
| さくら事務所等の住宅診断 | 検査料 | 建物の物理検査のみ。「買うべきか」は言わない | 物件ではなく**意思決定**を診断 |
| ADDress / 多拠点居住系 | 会員費 | 二拠点生活向け。購入前提ではない | 購入意思決定に直結した試住 |
| 生成AI汎用チャット | — | 一般論しか出ない。個人データ・地域データ・後悔事例DBがない | **後悔データセット**が堀 |

### 3.3 防御可能性（Moat）

1. **後悔データセット** — 購入後6ヶ月・24ヶ月の追跡調査で「どの条件を捨てた人が後悔したか」を蓄積。これは仲介会社が構造的に集められない（契約後に関係が切れるため）
2. **中立性ブランド** — 一度でも仲介や送客に寄れば失われる資産。後発の大手ほど模倣コストが高い
3. **夫婦合意フォーマット** — 2人の価値観を可視化する独自診断がスイッチングコストを生む
4. **試住ネットワーク** — Airbnb型の供給側（モデルハウス・空室・家具会社）提携が後から効く

## 4. ソリューションとプロダクト設計

### 4.1 Phase 1: NOT A HOME AI（最初に作るもの）

**入力**：年収／勤務地／家族構成・将来計画／価値観（30問診断）／希望エリア／検討中物件（任意）

**AI分析**：
- あなたが実際に重視している条件 TOP5（自己申告とのズレを提示）
- **あなたが後悔する条件 TOP5**（同条件世帯の後悔事例からの予測）
- 夫婦の優先順位ギャップマップ（争点の可視化と調停案）
- 「この家に向いている／向いていない」判定と根拠
- 捨てても後悔しない条件 / 絶対に捨ててはいけない条件

**出力**：40〜60ページのPDFレポート ＋ 夫婦で読む用のサマリー1枚

**価格**：29,800円（単発）／ 会員 9,800円/月に含む

**原価**：LLM推論費 数百円＋データ費。粗利率95%超。

### 4.2 Phase 2: Living Voice（元住民の声）

同条件・同エリアの**実際に住んだ人**の動画インタビュー＋Q&A。
- 立ち上げ：自社でインタビュー取得（1本1〜2万円で調達、初期300本）
- スケール：レポート購入者に購入後インタビューを依頼（＝**データフライホイール**）
- 検索軸は物件ではなく**「世帯像×エリア×後悔ポイント」**

### 4.3 Phase 3: Live Before Buy（試住）

**自社で家を持たない（Airbnb方式）**。
- 供給：分譲モデルハウス、販売中の空室、賃貸の空室、家具メーカーのショールーム
- 需要：レポート購入済みの高意欲ユーザー（＝供給側にとって最良の見込み客）
- 我々の役割：マッチングと体験設計のみ。3泊 / 7泊 / 30泊
- 供給側の動機：空室活用＋購入意欲の高いリードとの接点

### 4.4 会員モデル（権利の小口化ではない）

月9,800円で「試住権・レポート更新権・Living Voice閲覧権・専門家相談権」を提供。
**不動産の持分・権利は一切販売しない**（第6章参照）。SaaS＋コミュニティ型の会員権。

## 5. PMF仮説と検証設計

### 5.1 コア仮説

| # | 仮説 | 検証方法 | 合格ライン |
|---|---|---|---|
| H1 | 購入検討者は「診断」に3万円払う | LPで事前決済テスト（100人流入） | CVR 3%以上 |
| H2 | 真の痛みは夫婦の非合意である | 20人デプスインタビュー | 12人以上が合意困難を自発的に言及 |
| H3 | レポートが意思決定を実際に前進させる | 提供後2週間のNPS＋行動変化 | NPS 50以上／70%が「判断が進んだ」 |
| H4 | 中立性が価値の源泉である | 「仲介機能もつけたら？」への反応テスト | 過半数が「中立でいてほしい」 |
| H5 | 試住は重いがCVは高い | 30組の試住実証 | 試住者の購入決断率 60%以上 |

### 5.2 PMFの定義（North Star）

**North Star Metric：意思決定完了組数**（レポート提供後90日以内に「買う／買わない／保留を解除」の意思決定に至った組数）

サブ指標：
- 有料転換率（LP訪問→レポート購入）目標 3%
- 夫婦2人での利用率 目標 70%（＝合意形成プロダクトである証拠）
- 購入後6ヶ月の「後悔していない」回答率 目標 85%（業界平均比較で提示）
- 紹介経由獲得率 目標 30%（住宅購入は同僚・友人間で伝播しやすい）

### 5.3 「40%失望テスト」

レポート購入者に「NOT A HOMEが使えなくなったらどう感じるか」。**非常に残念 40%以上**でPMFと判定。

## 6. 法規制・コンプライアンス

### 6.1 基本方針 — グレーを狙わない

> **物件を紹介しない／媒介しない／契約に関与しない／特定物件の購入を勧誘しない。**

これにより、宅地建物取引業法の「宅地建物取引業」（売買・交換・媒介・代理の業として行う行為）に該当しない設計とする。提供するのは**一般的な意思決定支援と情報提供**に限定。

### 6.2 論点マトリクス

| 領域 | 法令 | リスク | 回避設計 |
|---|---|---|---|
| 物件紹介・媒介 | 宅地建物取引業法 | 免許なし営業 | 特定物件の斡旋・媒介を行わない。レポートは顧客の意思決定基準の整理に限定 |
| 権利の小口化 | **不動産特定共同事業法** | 無許可事業 | **不動産の持分・出資持分は販売しない**。会員権（役務提供の対価）に限定 |
| 試住の宿泊提供 | 旅館業法 / 住宅宿泊事業法 | 無許可宿泊営業 | 自社で宿泊提供せず、**適法に運営される施設（モデルハウス見学・民泊届出物件・マンスリー賃貸）へのマッチングに限定**。契約は供給者とユーザー間で直接締結 |
| 住宅ローン・資金助言 | 銀行法 / 金商法 / 貸金業法 | 無登録の媒介・投資助言 | 個別商品の媒介はしない。送客は提携先の登録事業者へ。投資推奨表現を禁止 |
| 保険の紹介 | 保険業法 | 無登録募集 | 募集行為を行わない。必要に応じて代理店登録を別途検討 |
| レポート表現 | 景品表示法 / 消費者契約法 | 断定的判断の提供 | 「予測であり結果を保証しない」旨の明示。効果保証表現の禁止 |
| 個人データ | 個人情報保護法 | 年収・家族情報の取扱い | 利用目的明示、第三者提供は都度同意、要配慮情報は取得しない |
| 口コミ | 景表法（ステマ規制） | 対価付き口コミ | 謝礼の有無を明示。編集・取捨選択の方針を公開 |

### 6.3 実行事項

- シード調達前に**不動産・金商法に強い法律事務所のリーガルオピニオン**を取得（費用 50〜100万円）
- 利用規約に「本サービスは宅地建物取引業に該当する行為を行わない」旨を明記
- 社内ルール：営業・CSが特定物件を推奨しないことを行動規範化

- どの表現が夫婦の合意を生んだか
これをプロンプトとレポート構造に還流させ、101件目以降の自動化率を上げる。

**資金効率の主張**：在庫（不動産）を持たず、免許を必要としないため、同じ市場を狙う競合に比べ**必要資本が1〜2桁小さい**。3年で年間1万組に到達しても、累積調達は20億円規模で足りる。

### 10.1 ピッチの骨格（10スライド）
