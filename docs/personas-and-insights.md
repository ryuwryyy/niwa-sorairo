# 序章 — この事業は「多面プラットフォーム」である

これまでの構想では、NOT A HOME を「顧客に売るサービス」として設計してきた。
**それが誤りだった。**

この事業は、**5者が揃って初めて回る**。誰か1者が欠けると成立しない。

```
        ③ シェアオーナー（お金を出し、自分も使う）
                    │
  ② 不動産事業者 ──┼── ① 投資家（会社に出資）
   （物件を出す）    │
                    │
        ④ 入居者・試住者（使う）
                    │
        ⑤ 地域・近隣（受け入れる）
```

**最も見落とされやすいのは⑤である。** 近隣の反対で潰れる新規事業は多い。
逆に言えば、**⑤を最初に設計した事業者はほとんどいない。**そこが我々の入り口になる。

# 第2部 — 制度の確定（これが事業の骨格を決めた）

素人が最も知らず、かつ事業の形を決めてしまう3つの制度を先に確定させる。

## 2.1 シェアオーナーは合法に作れる — 小規模不動産特定共同事業

**結論：作れる。ただし規模に上限がある。**

| 項目 | 小規模不動産特定共同事業 | 通常の不動産特定共同事業 |
|---|---|---|
| 手続き | **登録**（2017年改正で創設） | 許可 |
| 資本金 | **1,000万円** | 1億円（第1号事業） |
| 出資総額の上限 | **1億円以下** | 上限なし |
| **一投資家あたり** | **100万円以下** | 上限なし |

**この3つの数字が、事業の初期設計をそのまま決める。**

- 1棟あたり総額1億円まで → **地方の中古戸建なら数棟、都市部のマンション1室なら十分**
- 一人100万円まで → **富裕層ではなく、普通の人が参加できる**
- 資本金1,000万円 → **シード調達の範囲で届く**

> **制約が、事業の性格を決めてくれた。**
> 一人100万円という上限は、**「みんなで持つ」という思想と完全に一致している。**
> NOT A HOTEL が富裕層の別荘を12人で持つのに対し、
> **NOT A HOME は、普通の人が「これから住むかもしれない家」を共同で持つ。**

**やってはいけないこと**：登録を受けずに、不動産の持分や出資持分を販売すること。これは無登録営業にあたる。

## 2.2 地域は、国が味方についている — 改正広域的地域活性化基盤整備法

**2024年11月1日施行。**これは地域・近隣向けの説明で最も強い材料になる。

| 改正内容 | 我々にとっての意味 |
|---|---|
| **市町村が「特定居住促進計画」を策定できる** | 自治体が二地域居住を推進する立場になった |
| **市町村長が「二地域居住等支援法人」を指定できる**（NPO・民間企業等） | **我々が指定を受けられる可能性がある。**「勝手にやっている業者」ではなく「市町村が指定した支援法人」になれる |
| 住居専用地域で、二地域居住者向けの空き家改修等がしやすくなる特例 | 使える建物が増える |
| 支援法人は市町村長に計画の作成・変更を提案できる | 地域側に回れる |

**背景（法改正の根拠として国が示しているもの）**
20歳代で二地域居住に関心を持つ層が約3割、地方移住に関心を持つ層が約半数。

> **これが地域向けスライドの背骨になる。**
> 「私たちがやりたいこと」ではなく「**国が進めていることを、この町で実行する担い手**」として立つ。

## 2.3 宿泊は、自社で提供しない

試住を自社で宿泊事業として行えば旅館業法・住宅宿泊事業法の領域に入る。
**適法に運営されている施設（民泊届出物件・マンスリー賃貸・モデルハウス）へのマッチングに限定し、契約は供給者と利用者の間で直接結ぶ。**

## ステークホルダー③ シェアオーナー

### ペルソナ：**中村 理恵（38歳）＋ 夫（41歳）**

世帯年収1,100万円。都内賃貸。子ども1人。「いつか自然の近くに家が欲しい」と思っているが、別荘を買う勇気はない。**投資というより「参加」がしたい。**

### ② 彼らが直面する現実（別荘を「買う」場合）

| 項目 | 金額 |
|---|---|
| **年間維持費の目安** | **50万〜120万円** |
| 内訳 | 固定資産税 15〜25万円／別荘地の管理費 7〜30万円／水道光熱の基本料 5〜6万円／浄化槽の維持 5〜8万円 ほか |
| 別荘を持つハードルの1位 | **「維持費が高そう」26.9%** |
| 単独所有の構造的問題 | **使わなくても、管理費・積立金・固定資産税・光熱基本料が出ていく** |

**手放す理由として語られていること**
安価な宿泊施設が増え、別荘を維持する必要性が薄れた。年間維持費を考えると海外旅行に使ったほうが安い。

> **別荘の痛みは「買えないこと」ではない。「使わない期間も金が出ていくこと」である。**

### 先行事例：NOT A HOTEL の共同保有

| 方式 | 内容 |
|---|---|
| 1棟購入 | 1棟まるごと |
| **シェア購入** | **1棟（室）を最大12人で共同所有し、30日単位で利用** |
| 使わない日 | **ホテルとして貸し出して収入を得られる** |
| NFTメンバーシップ | 毎年1日単位で利用できる宿泊権。利用期間47年 |

> **「使わない日を収入に変える」**——これが共同保有モデルの核心である。
> NOT A HOME は同じ構造を、**別荘ではなく「これから住むかもしれない家」**に適用する。

### ④ 彼らが動く一言

> **「100万円から、みんなで一軒持ちませんか。」**
> **「あなたが使わない日は、家を探している誰かが泊まります。」**
> **「そして、あなた自身も泊まれます。**
> **——住んでみて気に入ったら、そこがあなたの次の家になるかもしれません。」**

**NOT A HOTEL との決定的な違い**：向こうは「別荘を持つ」。
こちらは**「移住や住み替えの候補地を、持ちながら試す」**。

### ③ 彼らが恐れていること（すべて先に開示する）

| 恐れ | 我々の答え |

| 途中でやめられるのか | 譲渡・中途解約の条件を契約前に明示する |
| 怪しい話では | **小規模不動産特定共同事業の登録事業者**として、法定の書面交付・説明を行う |
| 自分は使えるのか | 使えます。ただし**利用日数には上限がある**（持分に応じる） |

# 第6部 — 未検証事項と、次の90日

**調べ物は終わった。ここから先は人に会わないと分からない。**

| # | 検証すること | 方法 | 合格ライン | 期間 |
|---|---|---|---|---|
| **B1** | 試住で夫婦の優先順位が変わるか | 知人3組に実際に3泊してもらう | 3組中2組で条件の順位が入れ替わる | 4週 |
| **B2** | 物件が出てくるか | 地場不動産・マンスリー事業者 各3社に打診 | 3社が「条件次第で可」と答える | 3週 |
| **B3** | シェアオーナーが集まるか | 10人に100万円の共同保有を説明 | 3人が「話を詳しく聞きたい」 | 4週 |
| **B4** | 地域が受け入れるか | 1自治体の担当課に二地域居住支援法人について相談 | 門前払いされない | 2週 |
| **B5** | いくら払うか | B1の体験後に聞く（**先に聞かない**） | — | B1と同時 |

**最初にやるのは B4 である。**
理由：**役所への相談は無料で、数日で終わり、そして事業の正当性を最も強く裏付ける。**
「市町村と話しています」と言えるかどうかで、②③④への説明の強度がまるで変わる。
