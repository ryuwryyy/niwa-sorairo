# Part 2 — 突破プラン（致命傷になる5つ）

## 突破1：W1「時間がない」+ W2「窓が狭い」

### 問題の本質

物件単位のL2は、**顧客が物件を決めた後**にしか売れない。だが決めた後には時間がない。
つまり**商品と需要のタイミングが構造的にズレている**。値下げでもチャネルでも解けない。

### 解：商品を「物件単位」から「エリア単位」に前倒しする

> **エリア調査は、物件が決まる前にできる。だから時間圧力がない。**

これが本事業で最も重要な設計変更である。

| 商品 | タイミング | 時間圧力 | 在庫化 |
|---|---|---|---|
| **L2-A エリア実査**（新設・本命） | 候補エリアが3つに絞れた時点（**申込の数ヶ月前**） | なし | **できる** |
| L2-B 物件実査（従来） | 候補1〜2件に絞った後 | 強い | できない |

**L2-A エリア実査 98,000円**
- 対象：町丁目〜駅徒歩圏。**特定物件に依存しない**
- 内容：時間帯別騒音、夜間の明るさ、通勤動線の実測、保育園の実地確認、災害、人口動態、街の将来
- **既にアーカイブがあるエリアなら即納**（原価が劇的に低い＝密度の経済性と完全に整合）

**L2-B 物件実査 78,000円**（L2-A購入者向けの追加）
- エリアは済んでいるので、**物件固有の項目だけ**：日照・将来の日照リスク・管理規律・その建物の騒音
- **48時間で納品可能**。訪問は1〜2回で足りる（エリア情報が既にあるため）

### この転換が同時に解くもの

| 解ける壁 | 理由 |
|---|---|
| W1 時間がない | エリアは先に、物件は48時間に短縮 |
| W2 窓が狭い | 接点が「候補エリア選定期」に前倒しされ、**窓が数ヶ月に広がる** |
| W7 一生に一度 | エリア→物件の2回課金になり、客単価が176,000円に上がる |
| W11 工数 | エリア調査は再利用の塊。**在庫が積み上がるほど即納率が上がる** |
| W6 夫婦の合意 | 98,000円は14.8万より合意しやすく、**エリア調査は夫婦の議論の材料そのもの** |

> **合計単価は176,000円で従来より高いが、2回に分割され、かつ最初の1回に時間圧力がない。**

## 突破2：W8「現地に入れない」

### 問題の直視

マンションの掲示板・ゴミ集積所・共用廊下は**建物の管理下にある**。部外者が無断で立ち入れば不法侵入になりうる。プロトコルの中核が成立しない可能性がある。

### 解：アクセス階層を3段に分け、できる範囲を先に確定する

| 階層 | 手段 | 観測できるもの | 合法性 |
|---|---|---|---|
| **A 外周**（常に可能） | 公道・公開空地からの観測 | 前面道路の騒音、外観、ゴミ集積所（多くは道路面）、駐輪場、夜間の明るさ、人通り、周辺環境、日照、外から見える掲示物 | 問題なし |
| **B 同行**（顧客の内見に同席） | **顧客に同行する形で入館**。ホームインスペクターが確立した商習慣と同じ | 共用廊下、エントランス、掲示板、エレベーター、室内 | 顧客の権利に基づく |
| **C 書類**（顧客経由で請求） | 顧客が売主・管理会社に請求した資料を分析 | 長期修繕計画、修繕積立金、総会議事録、滞納状況 | 顧客の請求権 |

**運用ルール**
- **A だけで完結する商品を先に作る**（＝L2-Aエリア実査。これは全て外周で可能）
- B は L2-B の一部として「内見同行オプション」で提供。同行を断られた場合は A+C で納品し、**その旨をレポートに明記する**
- **無断で共用部に立ち入ることは、いかなる場合も禁止**

> 制約が商品設計を決める。**「外から見えるものだけで、これだけ分かる」を先に証明する。**

## 突破3：W4「実績ゼロで14.8万円」

### 解：レポートそのものを公開資産にする

無名の会社が高額商品を売る唯一の方法は、**商品を先に見せること**。

| 施策 | 内容 |
|---|---|
| **サンプルレポート全文公開** | 実在エリアの完全なレポートを1本、無料でPDF公開。**「やめるべき3つの理由」を含めて全部見せる** |
| **沿線エリアレポートの連載公開** | 1沿線の全駅について、実測データの要約を無料公開。**買う前に品質が分かる状態を作る** |
| 初期5件の価格 | **値引きはしない**（検証が壊れる）。代わりに「初回モニターとして実名掲載の許諾を得る」形で事例を確保 |
| 第三者の権威を借りる | 提携するインスペクター・建築士の実名と資格をレポートに記載する |

> **値引きで信用を買わない。情報の量で買う。**

## 突破4：W14「運用で規制を踏む」

### 問題の本質

最も危険なのは経営判断ではなく、**現場の調査員が善意で一線を越えること**。「お客様のために」隣人の情報を聞き込んでしまう。1件でも起きれば、届出義務違反か人権問題のどちらかになる。

### 解：システムで踏めなくする

| 施策 | 内容 |
|---|---|
| **入力フォームで物理的に禁止** | レポートは選択式＋実測値入力。自由記述は結論部のみ。**人物に関する項目が存在しない** |
| **禁止語の自動検出** | 提出時に国籍・出自・職業・家族構成・障害等の語を検出したらブロック |
| **調査員の初回研修を必須化** | 探偵業法の定義を条文で教える。「特定人の所在・行動」に触れた時点でアウトであることを明確化 |
| **聞き込みの全面禁止** | 近隣住民への接触そのものを禁止。**例外なし**。観測のみ |
| **顧客への事前開示** | 「調べないこと」を契約前に明示（→ 調査プロトコル Part A）。顧客からの越境依頼を断る根拠になる |

## 突破5：W16「中立性の誘惑」

### 解：定款と契約で、自分を縛る

| 施策 | 内容 |
|---|---|
| 定款への明記 | 事業目的に「不動産の売買・媒介を行わない」旨を記載 |
| 顧客への約束の明文化 | 利用規約に「不動産会社からの紹介料・送客手数料を受領しない」と記載。**破れば契約違反になる状態を作る** |
| 投資契約での宣言 | 収益源の制限を投資家にコミットし、変更には承認を要する設計にする |
| 社内KPI | 「買うな」と結論した比率 15〜25% を経営KPIに置く。**0%になったら中立性が壊れている警報** |

> 意志は折れる。**折れても戻れないように、先に縛る。**

# Part 3 — GTM：沿線ドミナント戦略

## 中核となる考え方

密度の経済性が事業の生命線である以上、**GTMは面ではなく線で設計する**。
全国のどこからでも注文を受けるのは、粗利を最も悪化させる行為である。

> **最初の1年、1沿線しか受けない。**

## 沿線の選定基準

| 基準 | 理由 |
|---|---|
| 30代共働きの一次取得が多い | ターゲットの密度 |
| 新築と中古が両方流通 | 調査需要の幅 |
| 駅数が10〜20 | アーカイブが1年で埋まる規模 |
| 都心から30〜50分 | 「都会で医療が近く、運転しなくていい」という希望条件に合致 |
| 環境の差が大きい | 幹線道路沿い／閑静な住宅街が混在＝**調査の価値が出やすい** |

## チャネル優先順位

| 順位 | チャネル | 根拠 | 立ち上げ |
|---|---|---|---|
| **1** | **ホームインスペクター・建築士との提携** | 顧客接点が既にあり、我々は建物以外を担当するので**競合せず補完する**。彼らの検査料に上乗せできる | 即時 |
| **2** | **FP・住宅ローンアドバイザー** | ヒアリングで実際に相談されていた職種。**購入検討の最初期に会っている** | 1ヶ月 |
| **3** | 沿線エリアレポートの無料公開 | W3（カテゴリ不在）とW4（実績ゼロ）を同時に解く。SEOの受け皿にもなる | 2ヶ月 |
| **4** | 恐怖検索の刈り取り | 「マンション 隣人 トラブル 調べる」「騒音 買う前 確認」等のロングテール | 3ヶ月 |
| **5** | 検討者コミュニティ | 「同じように検討している人のサービスがあれば良い」（ヒアリング事実）。**プロダクト化せずチャネルとして持つ** | 6ヶ月 |
| **6** | リノベ業者・工務店 | 「リノベ業者の候補を☆5で出してほしい」という要望に対応 | 9ヶ月 |

## 提携先への提案（最初の3行が全て）

> 「御社と競合しません。**建物は御社が、それ以外を私たちが見ます。**
> 検査に来られたお客様に、騒音・日照・管理状態・通勤動線の調査を追加でご提案いただけませんか。
> 紹介料はお支払いできません（中立性のため）。代わりに、**御社のお客様の満足度が上がる形**でお返しします。」

> ※ 紹介料を払えないのは弱点ではなく、**我々が紹介料を受け取らないことの裏返し**である。そう説明する。

## 12ヶ月シーケンス

| 期間 | 動き | 到達 |
|---|---|---|
| 0–1ヶ月 | 沿線決定。インスペクター・FP各5社に提案（R4） | 3社が試験提携 |
| 1–3ヶ月 | コンシェルジュMVP 5件（R1）。**入金で判定** | 5件入金 |
| 3–5ヶ月 | サンプルレポート全文公開。沿線レポート連載開始 | 認知の起点 |
| 5–8ヶ月 | L2-Aエリア実査を主商品化。工数カーブ実測（R2） | 累計30件 |
| 8–12ヶ月 | 提携経由の比率を30%へ。アーカイブで即納開始 | 累計50件・14h以下 |

# Part 4 — クリエイティブ戦略

## ブランドの態度：煽らない測定者

この商品は**恐怖に触れる**。だから最大のクリエイティブリスクは、**不安商法に見えること**である。

| やる | やらない |
|---|---|
| 事実を、静かに、数字で置く | 恐怖を増幅する |
| 「調べた結果、問題ありませんでした」も同じ重さで語る | 失敗談で煽る |
| 分からないことは「分からない」と書く | 断定・保証 |
| 顧客の判断力を信頼する | 「素人には無理です」と言う |

> **トーン：冷静な測定者。感情の言葉は顧客のもので、我々の言葉は数字である。**

## ポジショニング・ステートメント

> **候補を1〜2件に絞ったが決めきれない共働き夫婦にとって、**
> **NOT A HOME は、物件を売らない立場から現地を実測する調査会社である。**
> **不動産会社やポータルと違い、報酬が成約に連動しないため「やめたほうがいい」と言える。**

## コピーの中核

**主コピー**
> **内見は、晴れた日曜の昼しか見せてくれない。**

これが最も強い一文である理由：①全員が経験している事実 ②誰も悪者にしていない ③「では他の時間は？」という問いが自動的に立つ ④商品説明がそのまま続く。

**支柱コピー群**

| 用途 | コピー |
|---|---|
| 商品の説明 | 平日の夜に行きます。朝にも行きます。雨の日にも。 |
| 代理指標の説明 | **掲示板の「ご配慮ください」は、トラブルの化石です。** |
| 中立性 | 私たちは家を売りません。だから「やめたほうがいい」と書けます。 |
| 反証の必須化 | **すべてのレポートに「やめるべき3つの理由」が入っています。** |
| 規制の線引き | 隣の人のことは調べません。隣の**暮らし方**を読みます。 |
| 価格の正当化 | 4,000万円の0.37%で、4,000万円の間違いを止める。 |

## キャンペーン案

### ① 「30分では見えないもの」— 主軸キャンペーン

同一物件の**時間帯別の実測データを並べて見せる**。
休日昼 / 平日夜 / 平日朝の3枚を、騒音値・人通り・明るさとともに並置する。

> クリエイティブの主役は写真ではなく**数値**である。`58.4 dB / 21:40 / 曇` のような実測ラベルをそのままビジュアル要素にする。これは他社が真似できない——測っていないから。

### ② 「沿線カルテ」— コンテンツ／PR

選定した1沿線の全駅について、実測データの要約を無料公開する。
**報道価値がある**：「同じ沿線でも、夜間騒音は駅によって最大○dB違う」は、実測していなければ誰も言えない事実であり、メディアが引用しやすい。

これが同時に果たす役割：
- W3（カテゴリ不在）— 検索の受け皿を自分で作る
- W4（実績ゼロ）— 品質を購入前に見せる
- 沿線ドミナントの宣言 — その沿線で「あの会社」になる

### ③ 「買わない方がいいと言われた日」— 信頼の証明

**見送りを結論としたレポートの実例**を、顧客の許可を得て匿名で公開する。
自社の売上にならなかった案件を見せることが、中立性の唯一の証明になる。

## ビジュアル・アイデンティティの方向

| 要素 | 方向 |
|---|---|
| 主題 | 測量・実測。図面と計測器の世界であり、住宅広告の「幸せな家族」ではない |
| 数値の扱い | 等幅書体で、実測値・時刻・天候をセットで表示する。**データが装飾ではなく主役** |
| 写真 | 夕方・夜・雨天を積極的に使う。**晴れた休日の昼を使わない**ことがそのままメッセージになる |
| 色 | 測量オレンジをアクセントに、地は冷静なニュートラル。警告色を多用しない（煽りに見える） |
| 避けるもの | 家族の笑顔、青空の新築外観、「理想の住まい」的な語彙。これらは我々が疑っている対象そのもの |

## 禁忌リスト（クリエイティブ審査基準）

制作物は公開前に以下を全てチェックする。

- ❌ 特定の地域・建物を、住民の属性を理由に評価していないか
