# FigJam プラグイン — 聴く(Jevリサーチ)取り込み

`/research/` のインタビュー整理で **FigJamへ(コピー)** を押して得たデータを、FigJam のボードに配置します。

- **アフィニティ図** — 分類ごとのセクションに付箋を並べる(重要度 ★、話者つき。重要なものほど上)
- **行動フロー** — ジャーニー段階ごとのセクションにステップを時系列で置き、矢印でつなぐ。各段階のペインは赤い付箋で点線接続

## 使い方(開発版として読み込む)

1. Figma デスクトップアプリで FigJam ファイルを開く
2. メニュー → Plugins → Development → **Import plugin from manifest…** で、このフォルダの `manifest.json` を選ぶ
3. Plugins → Development → **聴く — Jevリサーチ取り込み** を実行
4. コピーしたデータを貼り付けて「ボードに配置する」

プラグインは外部通信しません(`networkAccess: none`)。データは貼り付けたものだけを使います。

## Miro の場合

インタビュー整理の **Miroへ(コピー)** は、分類ごとの列に並べたタブ区切りテキストです。
Miro のボードに貼り付けると、表のセルが付箋として置かれます(Miro の貼り付け仕様に依存)。
行動フローは **Mermaid** をコピーし、Miro や FigJam の Mermaid 取り込み機能で図にできます。
